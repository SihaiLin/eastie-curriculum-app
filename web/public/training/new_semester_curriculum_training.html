Navigation

系统导航路径

Grade → Category → Course Line → Unit → Lesson

常见顺序是：打开课程首页，选择年级 PG / PK / K1 / K2 / K3， 再选择课程类别 EL / CC / CE / PE，进入 course line 后选择 Unit，最后打开 lesson 或 unit 页面。

可把 home icon / curriculum dashboard 当作起点理解，重点是先选年级，再选类别，再看课程线。

Lesson reading

如何阅读 lesson 页面

常见页面元素

  • Unit overview
  • Course / lesson directory
  • Lesson outcome
  • Source
  • Language / key vocabulary where applicable
  • Teacher routine language
  • Activities or lesson steps
  • Resources
  • Feedback button

阅读原则

  • Not every course has exactly the same fields.
  • Language courses、Core courses、Graded Reading、Art/CE courses 可能会有不同结构。
  • 教师应跟随页面结构阅读，而不是强行把每节课套入同一个模板。

Resources

资源使用说明

资源可能的呈现形式

  • PDF
  • audio
  • video
  • book covers
  • Power Up resources
  • RAZ / Graded Reading resources

教师操作

  • 点击页面上的 PDF / resource 按钮。
  • audio / video 应从资源链接中打开或播放。
  • 不要使用旧的本地 file path。
  • 资源打不开时，通过 Feedback 或 admin 报告。

Feedback

反馈流程

每个相关 lesson page 都有 Feedback button。反馈不是投诉箱，而是课程改进通道。

适合提交的内容

  • 不清楚的 lesson content
  • 缺失的 resource
  • 错误的 link
  • classroom implementation issue
  • teaching 后的 suggestion

建议写清楚

  • what page
  • what lesson
  • what issue
  • what teacher observed or needs
反馈会和用户账号关联，admin 可以查看并更新反馈状态。

Teacher habits

教师 Do / Do Not

Do

  • 使用自己的账号登录。
  • 以系统页面作为主要参考。
  • 课前先检查 unit 和 lesson。
  • 上课前先打开 resources。
  • 遇到不清楚或坏掉的内容就提交 feedback。

Do not

  • 分享 login codes。
  • 编辑 source files。
  • 依赖旧截图或旧静态页面。
  • 只写 “not working” 却不说明 page details。
  • 在学校使用范围外下载或传播 licensed resources。

FAQ

常见问题

如果登录后看不到课程内容怎么办？

先确认是否已经进入 curriculum system，再检查年级、课程类别和 Unit 是否选对；必要时重新登录或联系 admin。

资源按钮点不开怎么办？

先刷新页面，再确认网络与资源链接。如果仍打不开，请在 Feedback 中写明页面、课程线、Unit 和资源名称。

为什么有些 URL 还叫 non-language？

这是历史路由标签。培训中可把它理解成 Core 或对应的 CE 路线，不需要把内部命名当成课程分类本身。

每个课程页面结构都一样吗？

不完全一样。不同课程线会有不同字段，老师应先看页面结构，再按照页面内容进行教学。
