# K1 Unit 1: Friends and Family

## Unit Metadata
- Level: K1
- Course Line: English Learning
- Unit Number: 1
- Unit Theme: Friends and Family
- Status: Sample for K Language canonical markdown v0.1
- Source Basis: Current generated Power Up data + web language classification scaffold

## Unit Focus
Children begin using simple English to notice and name people connected to friends and family. They hear and practise short identity questions and simple response chunks through Power Up-supported classroom routines.

## Unit Learning Outcomes
- Talk about friends and family.
- Talk about age.
- Listen to a real-life story and understand key details.
- Recognise initial letter sounds b, c, and m.
- Learn about family trees.

This unit should stay gentle and routine-based. Children are not expected to produce complete family descriptions independently. The current web page separates child-facing keywords from target sentences so teachers can quickly see what to model as words and what to model as sentence chunks.
