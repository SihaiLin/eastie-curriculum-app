# EASTIE Curriculum Source Files

This folder stores hand-managed curriculum source Markdown files.

Rules and schema guidance live under:

- `docs/rules/curriculum/`

Country Exploration source files live under:

- `country_exploration/{country_slug}/{grade}/`

Each Country Exploration grade folder should follow the current schema:

- `00_overview.md`
- `01_lesson_1.md`
- `02_lesson_2.md`
- `03_lesson_3.md`
- `04_lesson_4.md`
