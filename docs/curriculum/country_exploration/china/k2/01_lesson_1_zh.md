# 中国 · K2 · 第 1 课
## 山脉、河流与自然景观

## 1. 课程身份

- 国家 / 地区：中国
- 年级：K2
- 课次：4 课中的第 1 课

## 2. 课程重点

幼儿通过分类、比较和搭建自然景观，来探索中国不同的自然环境：山脉、河流、森林、竹林、稻田、草原和雪地。

## 3. 学习目标

幼儿将：

- 认出几种中国不同的自然景观；
- 按照可见特征（如水、树、田、雪、山）给景观图片分类和比较；
- 搭建或摆放一个简单的景观场景，认识到中国有许多不同的自然环境。

## 4. 教师语言

教师输入：

- Look at the mountain.
- This is a river.
- This is a forest.
- I see water.
- I see trees.
- Is it the same or different?
- Put the river here.
- Put the mountain here.
- Where is the forest?
- There are many places in China.

幼儿可能回应：

- mountain
- river
- forest
- bamboo
- field
- snow
- same
- different
- I see water.
- It is a mountain.
- Put it here.

幼儿也可以用指、分类、匹配、摆放、搭建，或在两张景观卡里选一张来回应。

## 5. 建议游戏与活动

### 活动 1：自然景观图片分类

**目的：**
帮助幼儿注意并按可见特征对中国自然景观进行分类。

**材料：**
山脉、河流、森林、竹林、稻田、草原、雪山的图片卡；湿地图片卡；篮子或分类垫。

**准备：**
准备 2–4 张简单的分类垫，比如"水""树""田""雪 / 山"。用图片而不是文字标签。

**玩法 / 做法：**
一次出示一张景观图，请幼儿说一说他们看到了什么：水、树、绿色、雪、山、田。然后请幼儿把图片放到对应的分类垫上。有些图片可能适合多个组，可以借此做简单比较。

分完以后，一起回顾几张分类垫，并说："China has mountains""China has rivers""China has fields""China has forests"。

**教师提示：**
不要求记住准确的地名。重点是注意景观类型和比较可见特征。

### 活动 2：搭一个山和河的景观

**目的：**
让幼儿用具体材料呈现自然景观。

**材料：**
积木、蓝色布或纸条、绿色纸或布、石头或散件、纸板、动物或树的道具（如有）。

**准备：**
在地面或桌面上布置几个分开的材料篮：积木用来搭山，蓝色材料表示河，绿色材料表示森林或田。

**玩法 / 做法：**
教师先示范做一个简单场景：用积木堆一座山，铺一条蓝色布做河，再在旁边放一些绿色材料。再请幼儿分组搭出自己的山和河场景。

用"Where is the river?""Put trees here""Is the mountain tall or short?"做提示。完成后，幼儿可以走一走、看一看每组做的场景。

**教师提示：**
K2 阶段要鼓励幼儿做选择、简短地解释。不要为了地理准确去"纠正"场景。

### 活动 3：相同还是不同——景观散步

**目的：**
通过动作和视觉选择支持 K2 的比较能力。

**材料：**
成对的景观图片，比如山 / 山、河 / 河、山 / 河、森林 / 田、雪 / 草原；地面标记或圈。

**准备：**
在每个站点放一张图片。准备几对图片，在游戏中展示给幼儿看。

**玩法 / 做法：**
教师出示两张图片，问"Same or different?"。幼儿可以用词、手势回应，或走到"相同"或"不同"的圈里。再问一个简单追问："Where is water?""Where are trees?""Which one has snow?"。

用几对图片重复几次。最后把所有图片放在一起，告诉幼儿中国有许多不同的地方。

**教师提示：**
以视觉比较为主，不做抽象解释。有些图片部分相同、部分不同，幼儿的合理观察都可以接受。
