# 中国 · K2 概览

## 1. 国家特点

中国是孩子们生活的国家，但 K2 幼儿已经准备好从自己熟悉的教室、城市和家庭日常再往外看一看。在本单元里，中国可以作为一个拥有许多不同自然环境的地方来介绍：山脉、河流、竹林、稻田、茶山、湿地、草原和雪地。也可以通过动物、植物、农田，以及自然和日常生活的联系来探索。

中国单元不应变成地理记忆课。幼儿不需要记住省份名称、复杂的地图知识或详细的地区信息。相反，他们应当注意到：中国有各种各样的地方，而不同的动物、植物和食物属于不同的环境。整体氛围应当是探索性的、可见的、可动手的、可比较的。

## 2. 年级视角

对 K2 幼儿来说，应当通过分类、比较、匹配和简单的联系来认识中国。幼儿可以比较山脉和河流、把动物和它们的生活环境连起来、把稻米或茶和稻田、茶山连起来，并把不同的自然元素组织到一张共同的中国自然地图上。

K2 的核心视角是：**"中国有许多不同的自然地方，不同的生物属于不同的地方。"**

K2 幼儿的回应可以是：分一分卡、搭一搭场景、连一连动物的家、比一比同和不同、把物品放到共同的地图上，并用短句说话。他们可以开始说出简单的关联，比如"panda in bamboo""rice in fields""river and mountain"。

## 3. 教室布置与关键元素

教室可以布置一个"自然中国"角：自然景观图片、动物卡、竹林、稻田图片、茶山图片、用来表示河流的蓝色布、绿色布或纸、用来表示田地和森林的绿色材料、用来搭山的积木，以及一张大的共同地面或墙面地图。布置应当支持比较和组织，而不是堆太多知识。

关键元素可以包括：

- 山脉和河流
- 竹林
- 稻田
- 茶山
- 湿地或池塘
- 大熊猫、丹顶鹤、金丝猴、雪豹或老虎
- 农田和植物图片
- 一张共同完成的"自然中国"地图

对 K2 来说，图片卡、散件、动物模型、布料、积木、篮子、匹配垫、教师做的地图底板，比文字解释或详细地图标签更有用。

## 4. 四课地图

### 第 1 课：山脉、河流与自然景观

幼儿通过图片、布料、积木和分类游戏，认识中国不同的自然景观。他们会注意到山、河、森林、竹林、稻田、草原和雪地。

本课建立起"中国有许多不同自然环境"这个基本认知。

### 第 2 课：中国的动物和它们的家

幼儿认识几种和中国有关的动物，并把动物和简单的生活环境连起来。他们会比较动物住在哪里、怎么动、需要什么样的环境。

本课帮助幼儿把动物和生活环境连起来，而不是把它们当成孤立的图片。

### 第 3 课：农田、稻田与茶山

幼儿探索自然如何和食物、人的生活连在一起。他们看稻田、茶山、蔬菜、水果和简单的农场场景，然后把植物和他们可能吃过的食物、喝过的饮品连起来。

本课把"我们吃的食物"推向"一些食物来自哪里"。

### 第 4 课：搭建一张自然中国地图

幼儿把景观、动物、植物和农田整合到一张共同完成的"自然中国"地图上。他们在共同展示里放入山脉、河流、森林、田地、动物和农场。

本课帮助幼儿把单元里的零散想法组织成一个可见的班级项目。
