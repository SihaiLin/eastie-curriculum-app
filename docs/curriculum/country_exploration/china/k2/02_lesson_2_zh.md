# 中国 · K2 · 第 2 课
## 中国的动物和它们的家

## 1. 课程身份

- 国家 / 地区：中国
- 年级：K2
- 课次：4 课中的第 2 课

## 2. 课程重点

幼儿认识几种和中国有关的动物，并把它们和简单的生活环境连起来：竹林、湿地、森林、山地或草原。

## 3. 学习目标

幼儿将：

- 认出几种和中国有关的动物；
- 用图片卡或小世界场景把动物和合适的生活环境匹配起来；
- 从动作、身体特征和家的角度比较动物，意识到不同的动物需要不同的地方生活。

## 4. 教师语言

教师输入：

- This is a panda.
- This is a crane.
- This is a monkey.
- Where does it live?
- It lives in the forest.
- It lives near water.
- Match the animal and the home.
- Is it big or small?
- Can it climb?
- Can it fly?
- Put the panda in the bamboo.

幼儿可能回应：

- panda
- crane
- monkey
- tiger
- snow leopard
- bamboo
- forest
- water
- mountain
- It can climb.
- It can fly.
- Panda in bamboo.

幼儿也可以通过匹配卡片、模仿动物动作、摆放动物模型、选择生活环境来回应。

## 5. 建议游戏与活动

### 活动 1：动物和生活环境匹配

**目的：**
帮助幼儿把动物和它们的家连起来，而不是把动物当作孤立的单词来记。

**材料：**
动物卡或模型：大熊猫、丹顶鹤、金丝猴、雪豹、老虎；环境卡或垫：竹林、湿地、森林、山地、草原。

**准备：**
把环境垫放在地面或桌上。动物卡放一个篮子里。用清晰、适合幼儿的图。

**玩法 / 做法：**
教师每次出示一种动物，请幼儿注意一个特征："It is black and white""It has long legs""It can climb""It is big"。然后幼儿选一个环境，把动物放过去。

教师示范简单的搭配："Panda in bamboo""Crane near water""Monkey in the forest"。幼儿如果可以，跟着说一说。

**教师提示：**
动物数量要控制。K2 用 4–5 种动物认真用，比一下子展示 10 种更有效。

### 活动 2：学一学动物的动作

**目的：**
用大动作强化动物特征和生活环境的概念。

**材料：**
动物图片卡；开阔空间；如方便可以用地标表示生活环境。

**准备：**
在教室里放几个生活环境地标：竹、水、森林、山。准备教师用的动物卡。

**玩法 / 做法：**
教师举起一张动物卡，请幼儿模仿这种动物的动作：熊猫慢慢走、丹顶鹤小心地迈步、金丝猴爬或够东西、老虎悄悄走、雪豹在山间移动。然后请幼儿走到对应的环境地标。

用简单语言："Can it fly?""Can it climb?""Go to the forest""Go to the mountain"。

**教师提示：**
划好安全的活动范围。动物动作可以想象，但要受控。

### 活动 3：搭一个动物的家

**目的：**
让幼儿通过搭建和散件呈现生活环境。

**材料：**
积木、乐高、绿色纸、蓝色布、棕色纸、纸筒、小动物模型或卡、叶子或自然感的材料（如有）。

**准备：**
为每个小组准备一份托盘：一种动物 + 一些环境材料。每组搭一个简单的"家"。

**玩法 / 做法：**
每组拿一张动物卡或一个动物模型。幼儿讨论这只动物应该住在哪里，然后搭一个简单的家。熊猫组可以做竹林、丹顶鹤组可以做水、雪豹组可以做山。

最后，各组把动物放回它搭的"家"里，并说出一个特征："water""mountain""forest"或"bamboo"。

**教师提示：**
重点是建立关系，不要求完美还原生活环境。简单的象征性表现就可以接受。
