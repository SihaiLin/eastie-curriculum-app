# 中国 · K1 · 第 3 课
## 日常生活中的中国食物

## 1. 课程身份

- 国家 / 地区：中国
- 年级：K1
- 课次：4 课中的第 3 课

## 2. 课程重点

幼儿通过角色扮演、食物道具、摆桌和简单的感官观察，认识熟悉的中国日常食物。

## 3. 学习目标

幼儿将：

- 认出熟悉的中国食物和餐桌物品；
- 在一个共同的"吃饭"场景里挑一挑、分一分、摆一摆；
- 参与假装吃饭的游戏，把中国和日常照料、吃饭和家庭习惯连起来。

## 4. 教师语言

教师输入：

- Look at the food.
- This is rice.
- This is noodles.
- This is a dumpling.
- This is a bowl.
- These are chopsticks.
- Put it in the bowl.
- Let’s eat.
- Do you like noodles?
- Here you are.
- Thank you.

幼儿可能回应：

- rice
- noodles
- dumpling
- bun
- bowl
- chopsticks
- I like noodles.
- Here you are.
- Thank you.

幼儿也可以通过选食物、端食物、摆放、假装吃、或指向自己喜欢的食物来回应。

## 5. 建议游戏与活动

### 活动 1：食物篮分类

**目的：**
通过分类和选择，帮助幼儿认出熟悉的中国食物和餐具。

**材料：**
仿真食物或图片卡：米饭、面条、饺子、包子、蔬菜、汤；碗、勺、安全的训练筷、托盘或篮子。

**准备：**
准备两到三个简单的分类篮，比如"食物""碗""餐具"。如果用标签，主要用图片而不是文字。

**玩法 / 做法：**
教师一件一件地出示食物。幼儿如果可以，试着说一说或指一指。然后请幼儿把物品分到不同的篮子里。教师用简单语言："This is rice""Put it here""Bowl""Food""Chopsticks"。

分完之后，每位幼儿从里面挑一个自己喜欢的食物，放到共同的桌垫上。

**教师提示：**
用孩子日常生活里吃过的食物。一节课里不要介绍太多地方菜。

### 活动 2：摆桌吃饭

**目的：**
把食物和照料、家人、吃饭习惯连起来。

**材料：**
小碗、小盘、小勺、儿童安全筷、餐垫、仿真食物、桌布或桌垫。

**准备：**
用矮桌或地垫布置一个共同的"吃饭区"。把仿真食物和餐具分开放到几个篮子里。

**玩法 / 做法：**
教师先示范摆一个位：碗、勺、筷子、食物。再请幼儿一起帮忙摆桌。有的孩子负责放碗，有的负责放食物，有的负责假装盛面条或饺子。

反复使用社交语言："Here you are""Thank you""Let’s eat""Do you like noodles?"。

**教师提示：**
这是一次生活实践 + 假装游戏。重点是参与和常规，不要求餐桌礼仪正确。

### 活动 3：饺子店角色扮演

**目的：**
给幼儿一个简单的角色扮演情境，练习和中国食物相关的语言和互动。

**材料：**
橡皮泥或柔软的仿真饺子、托盘、篮子、盘子、围裙（如有）、简单的店招、玩具收银机（如有）。

**准备：**
布置一个小的"饺子店"区。提前用橡皮泥压出简单的饺子，或者让幼儿在教师帮助下一起做。

**玩法 / 做法：**
幼儿轮流当"店员"和"顾客"。店员把饺子放到盘子里或托盘上，顾客挑选并"收到"食物。教师示范简单用语："Dumpling, please""Here you are""Thank you"。

活动结束后，可以把饺子店的一张照片或一幅画加到中国庆祝墙上。

**教师提示：**
角色扮演要简单。K1 完成一次"选 → 收 → 谢谢"的简单交换就够了。
