# 中国 · K1 概览

## 1. 国家特点

中国是孩子们生活的国家，因此本单元应从熟悉的生活出发，而不是遥远的知识。对 K1 幼儿来说，可以从色彩、节日氛围、城市画面、校园生活、日常食物、家庭作息和班级参与来认识中国。中国在这里应当是亲近、温暖、可见、属于自己的地方——是我所在的学校、我的家、我的城市、我的食物、我的节日。

中国单元不应变成一堂正式的地理、历史、政治或国情课。它要帮助幼儿意识到：中国不只是地图上的一个词，更是他们每天真实生活在其中的环境。红色和金色、星星、熟悉的城市场景、校园照片、碗筷、饺子、面条，以及孩子们一起做的装饰，都是具体的切入点。

## 2. 年级视角

对 K1 幼儿来说，应当通过个人、感官、视觉和日常生活体验来认识中国。幼儿不需要记住关于中国的任何知识。他们应当看到色彩和符号、认出熟悉的地方、触摸和摆放节日材料、玩食物道具、搭建简单的城市场景，并为班级展示出一份力。

K1 的核心视角是：**"这是我生活、上学、吃饭、玩耍和庆祝的地方。"**

K1 幼儿的回应可以是：看一看、指一指、选一选、认一认、走一走、摆一摆、做一做简单的作品，或说出一个词、说一句很短的话。并不要求进行口头解释。

## 3. 教室布置与关键元素

教室可以布置一个简单的中国角：红金色装饰、星星、小国旗、深圳和 EASTIE 的照片、熟悉的城市场景、孩子的画、食物道具、碗筷，以及一面共同的庆祝墙。布置应当让人感到这是孩子们生活其中的环境，而不是一块知识宣传板。

关键元素可以包括：

- 红色和金色
- 星星和简单的国旗形象
- 国庆节装饰
- 深圳城市图片
- EASTIE / 校园照片
- 教室与家庭生活图片
- 米饭、面条、饺子、包子、碗、筷子
- 孩子们为庆祝墙亲手做的作品

对 K1 来说，大幅图片、真实或仿真的生活物品、简单的触感材料、安全的道具和幼儿自制的展示物，比文字知识、省份名称或详细地图更有用。

## 4. 四课地图

### 第 1 课：中国色彩与国庆节

幼儿通过红色、金色、星星、国旗和国庆节装饰认识中国。他们注意颜色和形状，挥动小旗，匹配星星，并一起装饰中国庆祝角。

本课搭建进入中国单元的第一个视觉和节日切入点。

### 第 2 课：我的城市，我的学校，我的中国

幼儿把中国和自己每天生活的环境联系起来：深圳、EASTIE、教室、熟悉的建筑和上学路。他们看照片、匹配校园和城市画面，并搭建一个简单的城市场景。

本课帮助幼儿理解：中国就是他们日常生活发生的地方。

### 第 3 课：日常生活中的中国食物

幼儿通过角色扮演、图片、食物道具和简单的感官观察来认识熟悉的中国日常食物。他们用碗、筷子、盘子、食物卡片和角色扮演材料共同搭建一个"吃饭"场景。

本课把中国与日常生活照料、家人相处和熟悉的吃饭常规联系起来。

### 第 4 课：我的中国庆祝墙

幼儿把 K1 中国单元的体验汇聚成一面班级展示墙。他们加入颜色、星星、校园或城市的画、食物图片、班级照片和小装饰。

本课给幼儿一个可见的共同成果，让他们可以指着、选择并分享自己做的部分。
