# 中国 · K3 · 第 3 课
## 长城与传统建筑

## 1. 课程身份

- 国家 / 地区：中国
- 年级：K3
- 课次：4 课中的第 3 课

## 2. 课程重点

幼儿通过长城、塔楼、门楼、屋顶、桥、四合院等来探索中国的"大型结构"和传统建筑。他们用搭建材料来建造和比较这些形式。

## 3. 学习目标

幼儿将：

- 注意建筑的特征：墙、塔、门、屋顶、桥、四合院；
- 从高低、长短、形状、功能几个角度比较建筑形式；
- 合作搭建一个建筑模型，并解释一项设计选择，比如"这座塔很高"或"这座桥帮人过河"。

## 4. 教师语言

教师输入：

- Look at the wall.
- It is long.
- This is a tower.
- This is a gate.
- This roof is curved.
- Let’s build a long wall.
- Make it strong.
- Where is the bridge?
- How can people go through?
- Tell us about your building.

幼儿可能回应：

- It is long / tall / strong.
- This is a wall.
- This is a gate / tower / bridge.
- People go through here.
- I built a roof.
- Our wall is long.
- This bridge goes over the river.

## 5. 建议游戏与活动

### 活动 1：建筑图片寻宝

**目的：**
在搭建之前，先让幼儿认出中国传统建筑的可见部分。

**材料：**
长城、门楼、塔、宫殿屋顶、四合院布局、石桥的大图；以及"墙、塔、门、屋顶、桥"等小特征卡。

**准备：**
选少量清晰的大图。可以对图片做标记或裁剪，让特征更明显。准备对应的特征卡。

**玩法 / 做法：**
教师一次出示一张建筑图。幼儿在图里找特征：墙在哪里？门在哪里？屋顶是直的还是弯的？他们把特征卡和图配对。

**教师提示：**
重点是"看得见的形状和功能"。不要把课变成详细的历史讲解。

### 活动 2：一起搭"长墙"

**目的：**
支持合作搭建、空间推理和结构意识。

**材料：**
大块木制积木、乐高、纸板砖、小盒子、纸塔、布或纸做地形底座；如果方便可以加小人偶。

**准备：**
布置一个长的搭建区。准备一张简单的长城图片做参考。提前想好：是全班搭一面墙，还是分成几组各搭一段。

**玩法 / 做法：**
幼儿合作搭一面"长墙"，加上塔和门。教师提示他们想：长度、稳定性、通道、入口。如果时间允许，可以再加一座小山、一条路或一座小塔。

**教师提示：**
大型搭建要注意安全。控制结构高度，鼓励幼儿协商空间和分工。

### 活动 3：屋顶、门楼、桥——设计挑战

**目的：**
让幼儿在"设计变化"中探索建筑。

**材料：**
积木、磁力片、纸板条、纸屋顶形状、拱形片、胶带、小托盘、蓝色布做"水"、简单设计卡。

**准备：**
准备三张挑战卡：搭一座门、搭一个弯屋顶、搭一座过水的桥。把材料分到各站。

**玩法 / 做法：**
幼儿可以自己选一个挑战，或者轮换站点。搭一座能让人穿过的门、一个形状特别的屋顶、一座能过河的桥。最后每组讲一讲自己搭的东西是怎么"工作"的。

**教师提示：**
这个活动很适合 K3，幼儿可以解释功能：穿过、跨过、底下过、结实、很长、很高。鼓励解释，但不要纠专业术语。
