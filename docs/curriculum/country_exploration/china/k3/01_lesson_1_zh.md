# 中国 · K3 · 第 1 课
## 汉字与书写

## 1. 课程身份

- 国家 / 地区：中国
- 年级：K3
- 课次：4 课中的第 1 课

## 2. 课程重点

幼儿把汉字作为一种"可视的书写系统"来探索。他们会注意笔画、形状、简单的"像图画"的联系，并尝试毛笔式的笔触、拓印、描摹或匹配。

## 3. 学习目标

幼儿将：

- 注意到汉字是由笔画和形状组成的；
- 把一些简单的汉字和对应的图或意思连起来；
- 通过毛笔式笔触、拓印、描摹或匹配的方式在视觉上探索书写，并能就"什么是书写"说出一句简单的看法。

## 4. 教师语言

教师输入：

- Look at this Chinese character.
- What can you see?
- It has lines and strokes.
- This character means mountain / sun / tree.
- Let’s trace the strokes.
- Try it slowly.
- This is writing.
- We can write a message.
- Which character do you choose?
- Put your character on the wall.

幼儿可能回应：

- I see lines.
- It looks like a tree.
- This is sun / mountain / tree.
- I choose this one.
- I can write it.
- This is my character.
- It is difficult / easy.

## 5. 建议游戏与活动

### 活动 1：图与汉字配对

**目的：**
帮助幼儿注意到：一些汉字可以和简单的图、意思连起来。

**材料：**
图片卡和对应的简单汉字卡，比如：日、月、山、树、人、口、手或水。一次只用少量字。

**准备：**
准备清晰、图大字大的卡片。图片卡放一边，汉字卡放另一边。一次不要放太多字。

**玩法 / 做法：**
教师先出示一张图，比如"山"。请幼儿说一说看到了什么。再出示汉字，请幼儿注意形状和线条。幼儿两人一组或几人一组，把图片和汉字配对。

**教师提示：**
这不是正式的识字课。目标是"看见"和"建立意义联系"，不是准确记忆，也不是写字测验。

### 活动 2：大毛笔笔触实验室

**目的：**
让幼儿把"写字"体验为一种动作、控制和视觉创造。

**材料：**
大纸、水笔、粗毛笔、黑色颜料或稀释墨水替代品、托盘、围裙、抹布，以及笔画示例卡。

**准备：**
布置好防水的桌面或地面区。准备几种简单笔画的卡：横、竖、点、折、撇。

**玩法 / 做法：**
幼儿在大纸上练这些大笔触。教师示范慢而稳的动作。幼儿之后可以选一个简单汉字或"像汉字"的组合来试一试。可以独立做，也可以一起往一面"中国字墙"上贴。

**教师提示：**
接受 K3 水平的尝试。重点是方向、控制、力度和视觉表达。不要像教正式书法那样"纠正"孩子。

### 活动 3：汉字博物馆墙

**目的：**
帮助幼儿把"书写探索"整理并展示出来。

**材料：**
幼儿的毛笔作品、图字配对卡、可写小标签、展示板或墙面、胶带、名字卡。

**准备：**
在墙上分出几个区，比如"图""字""我们的字"。如需要可以准备简单标签。

**玩法 / 做法：**
幼儿选一组"图字配对"或一件"写字作品"贴到墙上。贴好以后，向同伴或教师说一说自己选的是哪个。能力较强的幼儿可以解释图和字之间的联系。

**教师提示：**
鼓励幼儿用简短清晰的句子说。表达不够自信的幼儿可以指一指或说一个词；K3 幼儿如果准备好了，可以邀请他们多说一句。
