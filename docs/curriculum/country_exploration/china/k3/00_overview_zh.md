# 中国 · K3 概览

## 1. 国家特点

中国是孩子们生活的国家。K3 幼儿已经准备好，不仅通过日常生活或自然环境，也通过人们所创造、建造、设计、书写和使用的事物来认识中国。在本单元里，中国可以作为一个"看得见创造"的地方来介绍：汉字、纸、丝绸、瓷器、传统建筑、长城、桥梁、高铁和现代城市天际线。

中国单元不应变成一堂朝代史课，也不应变成一份需要记忆的"发明清单"。幼儿不需要学习详细的时间线，也不需要复述成人化的"古代中国"讲解。相反，他们应当注意到：在中国这片土地上，人们在很长时间里创造了很多东西——书写方式、有用的材料、好看的图案、大型结构，以及现代交通系统。整体氛围应当是建造性的、可见的、项目式的、可解释的。

## 2. 年级视角

对 K3 幼儿来说，应当通过组织、比较、制作、解释和展示来认识中国。幼儿可以比较古代和现代的创造、观察材料怎么被使用、搭建结构、制作视觉展示，并解释他们发现的一两件事。

K3 的核心视角是：**"在中国，人们创造、建造、设计和使用了什么？"**

K3 幼儿的回应可以是：画一画、搭一搭、分一分、贴一贴、组内讨论、简单的展示、模型制作、班级小博物馆工作。他们可以开始说出简单的关联，比如"纸是用来写字的""桥帮人过河""火车带人到处走""墙上有塔楼和门"。

## 3. 教室布置与关键元素

教室可以布置一个"创造中国"角：汉字卡、毛笔字例、纸和布的样本、青花纹样图片、传统屋顶和门楼图片、长城图片、桥梁照片、高铁图片，以及深圳或其他现代城市画面。布置应当支持"做"和"解释"，而不只是装饰。

关键元素可以包括：

- 汉字和毛笔笔触
- 纸和印刷 / 拓印
- 丝绸质感的布和质感对比
- 青花纹样
- 长城
- 传统屋顶、门楼、四合院和桥
- 高铁和现代桥梁
- 深圳或现代城市天际线

对 K3 来说，图片卡、简单标签、材料样本、搭建材料、设计模板、小组展示板和展示空间，比长篇文字介绍更有用。

## 4. 四课地图

### 第 1 课：汉字与书写

幼儿把汉字作为一种"可见的书写系统"来探索。他们会注意笔画、形状、简单的"像图画"特征，并尝试毛笔式的笔触、拓印、描摹、匹配或汉字展示。

本课把"书写"作为人们创造并用来交流的事情来引入。

### 第 2 课：纸、丝绸与瓷器

幼儿通过材料和花样的视角来探索中国的"造物"传统。他们比较纸、布料、光滑表面、印刷痕迹、青花纹样和简单的工艺过程。

本课让幼儿通过材料和"动手做"来理解中国，而不是靠记忆"发明清单"。

### 第 3 课：长城与传统建筑

幼儿探索中国的"大型结构"和传统建筑形式：长城、塔楼、门楼、屋顶、桥和四合院。他们用积木、乐高、纸板或散件来搭建、比较和设计。

本课重点是结构、形式、功能和合作搭建。

### 第 4 课：现代中国：火车、桥梁与城市

幼儿通过高铁、桥、地铁、塔楼和现代城市来探索现代的"被创造的中国"。他们把古代和现代的"造物"通过一次班级展示或"中国创造小博物馆"连起来。

本课通过项目工作和简单的展示，把整个单元收拢起来。
