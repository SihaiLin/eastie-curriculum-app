# 德国 · K3 · 第 1 课
## 移动中的德国——路线与系统

## 1. 课程身份

- 国家 / 地区：德国
- 年级：K3
- 课次：4 课中的第 1 课

## 2. 课程重点

幼儿通过交通系统认识德国：汽车、火车、公路、铁路、桥、隧道、车站和路线。重点是把"部分"组织成"系统"，并解释人和车是怎么从一个地方到另一个地方的。

## 3. 学习目标

幼儿将：

- 把交通元素组织成一套简单的系统，包括路线、车站、桥、隧道和终点；
- 用"路线语言"解释汽车和火车的不同行驶方式；
- 做一张简单的德国交通图或模型，带有标签、箭头和连起来的路径。

## 4. 教师语言

教师输入：

- A system has parts that work together.
- Where does the route start? Where does it end?
- Cars need roads. Trains need tracks.
- Add an arrow to show the way.
- Explain your route to the group.

幼儿可能回应：

- start / end / route / station / bridge / tunnel
- cars go on roads / trains go on tracks
- first / next / then / because

## 5. 建议游戏与活动

### 活动 1：交通系统分类

**目的：**
从"把东西分类"再往前走一步，进入"系统思考"。

**材料：**
交通卡、路线卡、车站卡、桥和隧道的图、箭头、大的纸底板。

**准备：**
准备一块空白的路线板，标好两个终点。

**玩法 / 做法：**
幼儿把交通材料分成"系统部件"：车、路线、停靠、连接、终点。然后把部件放到板上，用箭头表示移动方向。

**教师提示：**
"系统"这个词要自然地用，但保持具体："很多部分一起工作"。

### 活动 2：设计一个"路线问题"

**目的：**
鼓励规划和解释。

**材料：**
积木、马路片、轨道、桥片、隧道片、汽车、火车、终点卡。

**准备：**
设一个简单挑战："把人从镇子送到森林"或"把车站和城堡连起来"。

**玩法 / 做法：**
小组设计一条路线。决定在哪里放公路、轨道、桥或隧道，试一下车能不能顺利通过，再调整。

**教师提示：**
提示幼儿讲一讲设计选择。解释保持简短、关注功能。

### 活动 3：路线图展示

**目的：**
支持 K3 水平的"组织"和"分享"。

**材料：**
搭好的路线模型、标签、箭头、指物棒、相机或平板做记录。

**准备：**
加好起点、车站、桥、隧道、终点的标签。

**玩法 / 做法：**
每组展示系统的一个部分。幼儿可以说"这里是什么开始""那里是什么动过去""接下来发生什么"。

**教师提示：**
不要求背国名知识。学习在"组织"和"解释模型"上。
