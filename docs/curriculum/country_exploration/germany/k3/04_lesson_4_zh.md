# 德国 · K3 · 第 4 课
## 德国小博物馆——搭建、贴标签和展示

## 1. 课程身份

- 国家 / 地区：德国
- 年级：K3
- 课次：4 课中的第 4 课

## 2. 课程重点

幼儿做一个迷你博物馆，把德国单元的内容整理到几个清晰的分区：交通系统、设计与工程、森林和故事、建筑或钟表。重点是策展、贴标签、解释，以及向同学展示自己做的内容。

## 3. 学习目标

幼儿将：

- 把德国相关作品分类到班级迷你博物馆的几个区里；
- 做简单的标签、箭头或小段说明，帮助参观者看懂；
- 用简短的解释性语言，介绍自己挑出的一件物品、模型、图片或故事元素。

## 4. 教师语言

教师输入：

- Which section does this belong to?
- Add a label so visitors can understand.
- What did you make?
- Why did you put it here?
- Present one thing from the museum.

幼儿可能回应：

- transport / forest / bridge / clock / castle / story
- this is my bridge / it is strong / it goes here
- because / first / next / I made

## 5. 建议游戏与活动

### 活动 1：博物馆分区布置

**目的：**
帮助幼儿分类和摆放前几课积累的作品。

**材料：**
幼儿做的模型、画、照片、故事地图、交通路线、分类标志、展示桌或地垫。

**准备：**
准备四个可能的博物馆分区：交通、设计、森林故事、建筑与钟表。

**玩法 / 做法：**
幼儿选一件作品，决定它属于哪一区，放进去，再看看这一区里有没有相似的东西。

**教师提示：**
有些作品可以同时归到多区。把它当作讨论机会，不要去"纠正"。

### 活动 2：标签和箭头工作坊

**目的：**
支持早期策展和"说明性展示"。

**材料：**
小卡片、马克笔、印好的词或图标签、箭头、胶带、幼儿照片。

**准备：**
准备标签模板，标好"放一个词 / 画 / 教师代写句子"的位置。

**玩法 / 做法：**
幼儿为挑出来的物品做标签。可以写、描、画或口述。再加箭头表示运动或功能，比如路线方向、桥的支撑。

**教师提示：**
标签要"有功能"，不是"只装饰"。要能帮参观者看懂他们看到的是什么。

### 活动 3：迷你博物馆参观

**目的：**
给 K3 幼儿一次有意义的展示体验。

**材料：**
完成的小博物馆、指物棒、访客证或简单的路线卡。

**准备：**
把展示布置好，让小组可以安全地在里面走动。

**玩法 / 做法：**
幼儿轮流展示一区或一件物品。说出它是什么、说出一个特征、再展示它怎么工作或为什么属于这一区。

**教师提示：**
展示可以很短。重点放在"清楚""自信"和"和自己作品连起来"。
