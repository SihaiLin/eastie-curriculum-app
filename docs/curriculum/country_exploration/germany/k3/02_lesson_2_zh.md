# 德国 · K3 · 第 2 课
## 设计与工程——桥、汽车和有用的物品

## 1. 课程身份

- 国家 / 地区：德国
- 年级：K3
- 课次：4 课中的第 2 课

## 2. 课程重点

幼儿通过"设计和工程思维"来认识德国。他们探究一些简单的设计问题：怎么让桥更结实、怎么让车开得更远、怎么为一条路线选材料。本课强调测试、改进和解释。

## 3. 学习目标

幼儿将：

- 用搭建材料、车辆、桥或活动部件探究一个简单的设计问题；
- 根据"试一试之后发生什么"来测试和改进一个结构或物品；
- 用一句简单的话，引用测试中的证据，解释一个设计选择。

## 4. 教师语言

教师输入：

- What problem are we solving?
- Test it. Does it work?
- How can we make it stronger?
- What did you change?
- Explain your design choice.

幼儿可能回应：

- strong / weak / high / low / stable / move
- it works / it falls / we changed this
- because / first / then / next

## 5. 建议游戏与活动

### 活动 1：桥的承重挑战

**目的：**
把"工程"引入为"测试 + 改进"。

**材料：**
木制积木、纸板条、纸筒、小玩具车、计数物或轻的小重物。

**准备：**
在两个矮积木支架之间设一个"缺口"。

**玩法 / 做法：**
幼儿在缺口上搭一座桥，试玩具车能不能开过去；如果桥弯了或塌了，就改进。教师鼓励他们比较：宽 / 窄、高 / 矮、支撑多 / 少。

**教师提示：**
重点是过程，不是"赢"。失败的设计也有用，因为可以让幼儿去改进。

### 活动 2：小车滑行测试

**目的：**
把"车怎么动"和"路面、坡度、设计"连起来。

**材料：**
玩具车、斜坡、纸板马路、不同材质的表面（毛毡、纸、垫子、光滑板）。

**准备：**
设两到三条短测试道。

**玩法 / 做法：**
幼儿让小车从斜坡上滑下来，观察哪辆车开得更远、哪辆停得更早。可以换坡度或表面再试。

**教师提示：**
用简单语言：farther、slower、smoother、rougher。不要把它变成正式物理课。

### 活动 3：有用物品设计板

**目的：**
帮助幼儿把"设计思考"用视觉方式整理出来。

**材料：**
纸板、画笔、桥 / 汽车 / 钟表 / 工具的图片卡、箭头、标签。

**准备：**
准备一块"三段式"展板：问题、设计、测试。

**玩法 / 做法：**
幼儿从本课里选一个设计问题，用画或图片贴的方式展示他们试过什么。再加箭头或标签解释过程。

**教师提示：**
K3 幼儿可以开始"画"自己的思考。画和教师代写的文字都可以。
