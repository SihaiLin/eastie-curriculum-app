# 德国 · K3 概览

## 1. 国家特点

德国是 K3 一个有用的主题，因为可以支持关于"设计、系统、工程、建筑、森林、故事和音乐"的项目式思考。幼儿可以整理"人是怎样移动、建造、制作、讲故事、设计有用物品"的信息。本单元不应变成"知识堆叠"的地理或历史课。重点应当放在"德国是一个由路线、建筑、发明、工艺、森林和文化故事组成的地方"。

## 2. 年级视角

对 K3 幼儿来说，应当通过组织、解释、设计和展示来探索德国。幼儿可以做一张路线图、比较多样的交通系统、设计一座桥或一个小镇、把森林和传统故事连起来、策划一个小的"德国制造与设计"展示。核心视角是：**"人是怎么设计系统、地方和物品的？"**

## 3. 教室布置与关键元素

教室可以布置一个"德国项目区"：简单层面的地图、交通图片、汽车和火车模型材料、桥和建筑参考、黑森林图片、童话风格的故事道具、钟表和齿轮画面、用来放幼儿设计作品的展示板。K3 幼儿可以使用标签、箭头、分类和简短的展示。

## 4. 四课地图

### 第 1 课：移动中的德国——路线与系统

幼儿把汽车、火车、公路、铁路、桥、隧道、车站组织成简单的交通系统，并解释人是怎么从一个地方到另一个地方的。

### 第 2 课：设计与工程——桥、汽车和有用的物品

幼儿探究简单的设计问题：怎么让桥更结实、怎么让车开得更远、怎么为一条路线选材料，然后测试和解释他们的设计。

### 第 3 课：森林、故事与文化想象

幼儿通过地图、故事路径、人物卡和剧场式复述，认识德国森林场景和适合幼儿的传统故事元素。

### 第 4 课：德国小博物馆——搭建、贴标签和展示

幼儿把交通、森林、建筑、钟表、设计元素做成一个小的项目展示，并整理、挑选作品向同学介绍。
