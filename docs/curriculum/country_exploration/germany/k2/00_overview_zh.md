# 德国 · K2 概览

## 1. 国家特点

德国很适合 K2，因为它最有幼儿接触度的元素可以被分类、比较、连起来、搭建：不同种类的交通工具、道路和铁路系统、森林和小镇、城堡和房屋、钟表和简单的机械结构。单元应当让德国感觉成"一个人们设计路线、搭建建筑、使用机器、居住在森林和城镇之间的地方"。

## 2. 年级视角

对 K2 幼儿来说，应当通过分类、比较、排序和简单因果关系来探索德国。幼儿可以比较公路和铁路交通、按形状和功能给建筑分类、把森林和动物和家连起来，并观察简单的活动部件是怎么动的。核心视角是：**"东西是怎么被造出来、连起来、使用的？"**

## 3. 教室布置与关键元素

教室可以布置一个"交通与搭建"区：胶带马路、火车轨道、车辆、桥片、积木、齿轮或简单的活动部件、城堡和木屋图片、森林材料和分类卡。环境应当能邀请幼儿分类和搭建：公路 / 铁路、城镇 / 森林、桥 / 隧道、轮子 / 轨道、房子 / 城堡 / 钟表。

## 4. 四课地图

### 第 1 课：公路、汽车和火车——分类和比较

幼儿比较多样的汽车、火车、公路、轨道、桥和隧道。他们给交通材料分类，并按不同的"行驶规则"搭建路线。

### 第 2 课：森林、动物和小镇

幼儿探索"森林和城镇"之间的联系：树、小路、动物、房子、住在自然环境附近的人。

### 第 3 课：城堡、房子和建筑形状

幼儿比较多样的城堡、镇上的房子、屋顶、塔、墙、窗、桥，并按"看得到的特征"搭建和分类。

### 第 4 课：钟表、轮子和简单机械结构

幼儿探索布谷鸟钟的画面、轮子、齿轮、转动部件和简单因果动作，然后在德国展示里加入一个会动或假装会动的部分。
