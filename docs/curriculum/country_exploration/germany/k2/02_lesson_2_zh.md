# 德国 · K2 · 第 2 课
## 森林、动物和小镇

## 1. 课程身份

- 国家 / 地区：德国
- 年级：K2
- 课次：4 课中的第 2 课

## 2. 课程重点

幼儿通过森林和小镇认识德国。本课重点是"联系"：森林有树和动物；小镇有房子、小路、人；有些地方紧挨着自然。幼儿通过分类、匹配和搭建来理解"森林和小镇"的关系。

## 3. 学习目标

幼儿将：

- 识别并分类简单的森林和城镇元素：树、动物、房子、小路、人；
- 把动物和物品放到森林—小镇场景里合适的位置；
- 用简单的"相同 / 不同"语言比较自然元素和人造元素。

## 4. 教师语言

教师输入：

- Is this from the forest or the town?
- Trees are in the forest.
- Houses are in the town.
- The path connects the forest and the town.
- What is natural? What is built?

幼儿可能回应：

- forest / town / tree / house / path / animal
- same / different
- in the forest / in the town / near the trees

## 5. 建议游戏与活动

### 活动 1：森林还是小镇？

**目的：**
帮助幼儿分类"自然的"和"人造的"元素。

**材料：**
图片卡或实物：树、动物、蘑菇、房子、屋顶、马路、人、店铺、小路。

**准备：**
设两个大区，分别用图片标"森林"和"小镇"。

**玩法 / 做法：**
幼儿把卡片分到"森林"或"小镇"。对于"两边都能放"的卡（比如小路、人），教师可以请幼儿把它放到两个区的中间。

**教师提示：**
不要给每张卡都强求一个唯一正确答案。有的卡正好可以引出讨论。

### 活动 2：搭一片"森林—小镇"边界

**目的：**
让"自然—聚落"的关系变得看得见。

**材料：**
积木、绿色布、纸树、房子片、马路片、小路标记、小动物。

**准备：**
准备一张大底板，一边是"森林"，一边是"小镇"。

**玩法 / 做法：**
幼儿一边搭树和动物，另一边搭房子和马路，再用小路把它们连起来。问："人会走哪里？动物会待在哪里？"

**教师提示：**
动物内容保持简单、不可怕。重点放在"地点之间的关系"。

### 活动 3：相同和不同——看图说话

**目的：**
用真实或写实的德国图片支持视觉比较。

**材料：**
德国森林、小镇、木屋、小路、树的图片。

**准备：**
选 4–6 张图片，要有明显对比。

**玩法 / 做法：**
一次出示两张图。幼儿说出相同和不同：树、房子、马路、屋顶、颜色、动物、人。

**教师提示：**
保持对话式。说一个词就够了。
