# 德国 · K2 · 第 3 课
## 城堡、房子和建筑形状

## 1. 课程身份

- 国家 / 地区：德国
- 年级：K2
- 课次：4 课中的第 3 课

## 2. 课程重点

幼儿通过德国城堡、镇上的房子、屋顶、塔、墙、桥、门、窗来探索。重点是观察和比较"看得到的"建筑特征，然后用这些特征做搭建。

## 3. 学习目标

幼儿将：

- 注意城堡和房子的可见特征：塔、墙、屋顶、门、窗；
- 按形状、大小、功能或反复出现的特征给建筑分类或比较；
- 用挑出来的建筑特征搭一座城堡或一座镇上建筑。

## 4. 教师语言

教师输入：

- This building has a tower.
- This house has a roof and windows.
- Is it tall or short?
- What is the same? What is different?
- Build a wall. Add a gate.

幼儿可能回应：

- tower / wall / roof / door / window / bridge
- tall / short / big / small
- same / different / castle / house

## 5. 建议游戏与活动

### 活动 1：建筑特征寻宝

**目的：**
引导幼儿观察建筑的细节。

**材料：**
德国城堡、木屋式镇房、桥、门、屋顶的大图；特征卡。

**准备：**
准备特征卡：塔、屋顶、墙、门、窗、桥。

**玩法 / 做法：**
出示一张建筑图。幼儿把特征卡和图上能看到的东西配对。指一指图里的塔、屋顶、窗或门。

**教师提示：**
用清晰、形状分明的图片。避免长时间的历史讲解。

### 活动 2：城堡还是房子？

**目的：**
帮助幼儿从功能和外观上比较多样的建筑。

**材料：**
建筑图片卡、两个标了"城堡"和"房子"的呼啦圈或托盘、可选第三个标"桥 / 门"。

**准备：**
把建筑卡混放在桌上或地面垫上。

**玩法 / 做法：**
幼儿把图片分到"城堡"或"房子"里。问他们是怎么决定的：塔、屋顶、墙、很多窗、大门。

**教师提示：**
重点是"比较"，不是"完美分类"。有的建筑可以一起讨论。

### 活动 3：搭出"建筑特征"

**目的：**
把观察变成搭建。

**材料：**
木制积木、乐高、纸板长方形和三角片、做塔用的纸筒、桥片。

**准备：**
把材料按可能的"特征"分组放好：墙、塔、屋顶、门、桥。

**玩法 / 做法：**
幼儿先选一张特征卡，先搭那一部分。再把各组的部分拼到一起，做成一座城堡或一条镇上街道。

**教师提示：**
请幼儿说出或指出他用了哪个特征。不要求做出"像真"的模型。
