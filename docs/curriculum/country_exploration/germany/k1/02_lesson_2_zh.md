# 德国 · K1 · 第 2 课
## 火车、轨道和车站

## 1. 课程身份

- 国家 / 地区：德国
- 年级：K1
- 课次：4 课中的第 2 课

## 2. 课程重点

幼儿通过火车、轨道和车站认识德国。重点是拼装、跟着路线走、安全地开小火车，并在玩中注意长 / 短、一起 / 分开、进 / 出。

## 3. 学习目标

幼儿将：

- 注意到火车、轨道、车站、隧道这些具体的交通元素；
- 在成人支持下，参与搭建或使用一条简单的火车路线；
- 通过放、拼、推、等待或一个词对"路线语言"做出回应。

## 4. 教师语言

教师输入：

- This is a train.
- Put the train on the track.
- Join the tracks together.
- The train goes to the station.
- Wait. Now go.

幼儿可能回应：

- train / track / station / tunnel
- go / stop / long
- joining, placing, moving, waiting

## 5. 建议游戏与活动

### 活动 1：轨道搭建师

**目的：**
用火车轨道游戏支持手眼协调和合作搭建。

**材料：**
木质或塑料火车轨道、玩具小火车、小车站积木、隧道片。

**准备：**
把轨道片放在几个篮子里，预先搭好一条示范轨道做参考。

**玩法 / 做法：**
请幼儿一起帮忙拼接轨道。教师帮忙固定，并说出动作词：join、turn、long、short。路线搭好后，幼儿用小火车沿线开。

**教师提示：**
不要求每位幼儿都搭完整条路线。拼一部分、放一放、搭一节，都是有效的参与。

### 活动 2：车站停靠游戏

**目的：**
练习受控的"动"和"等"。

**材料：**
玩具小火车、车站卡或积木、小人偶、停 / 走卡。

**准备：**
在轨道沿线设两到三个车站。

**玩法 / 做法：**
幼儿把火车从一个车站开到另一个车站。每到一站就停一下，放上小人偶或挥挥手。教师用简单提示："Stop at the station""People get in""Train goes"。

**教师提示：**
节奏保持可预期。这样 K1 幼儿不需要太多语言就能加入。

### 活动 3：隧道和桥的火车游戏

**目的：**
让幼儿在开火车时注意到"上、下、进、出"。

**材料：**
积木、纸板隧道、低矮的桥片、火车轨道、玩具小火车。

**准备：**
在轨道上搭一个隧道和一座低矮的桥。

**玩法 / 做法：**
请幼儿把火车开过隧道，并根据搭建的方式从桥上或桥下通过。幼儿可以继续加积木，把隧道加长。

**教师提示：**
"上下进出"只作为语言接触。幼儿能正确地开火车通过，就是有效的回应。
