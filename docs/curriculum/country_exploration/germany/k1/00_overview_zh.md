# 德国 · K1 概览

## 1. 国家特点

德国是一个非常适合幼儿的国家探索主题，因为可以用具体、可搭建的元素来引入：汽车、火车、道路、森林、城堡、小镇房屋、钟表、简单的故事场景。它不应被讲成一份知识清单。对 K1 来说，最好的方式是"一个可以动、可以搭、可以看到轮子、可以走树林、可以看到房子和故事画面"的地方。

## 2. 年级视角

对 K1 幼儿来说，应当通过"看、触摸、动作、动手做"来探索德国。幼儿可以推着小车在马路线上走、搭建火车轨道、用积木堆城堡、走一段假装的小路、并在房子和钟表里注意简单的形状。核心视角是：**"我们可以推动什么、可以搭建什么、可以注意到什么？"**

## 3. 教室布置与关键元素

教室可以布置一个"德国角"：玩具车、火车轨道、马路胶带、森林布或纸树、城堡和小镇图片、木制积木、轮子、桥片、简单的布谷鸟钟画面。布置应当让人感到"可以动手、可以搭建"，而不是信息性的。对 K1 来说，大图片、真实物品、玩具车、积木和简单的故事道具，比地图或文字更有用。

## 4. 四课地图

### 第 1 课：汽车、马路和移动

幼儿通过汽车、马路、轮子、隧道和移动来认识德国。他们推车、沿着马路线走，并注意快 / 慢、停 / 走、直线 / 弯路的对比。

### 第 2 课：火车、轨道和车站

幼儿通过搭建、拼装、做车站和让火车安全地开过路线，认识火车和轨道。

### 第 3 课：森林、房屋和故事小路

幼儿走进一片简单的"德国森林和小镇"：树、房子、小路、故事道具。他们走一段假装的小路，并搭建小房子。

### 第 4 课：搭建一座迷你德国小镇

幼儿把道路、轨道、汽车、火车、树、房子和一座城堡组合成一座共同的迷你德国小镇，然后走一走，分享自己做的部分。
