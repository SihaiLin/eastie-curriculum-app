# 肯尼亚 · K3 · 第 2 课
## 稀树草原生态系统——动物、需要和关系

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K3
- 课次：4 课中的第 2 课

## 2. 课程重点

幼儿把肯尼亚稀树草原当作一个简单的"生态系统"来探究。他们把动物、植物、水、阴凉和空间组织成关系。课程保持符合年龄：动物需要食物、水、空间和安全的地方；不同动物用环境的方式不同。

## 3. 学习目标

幼儿将：

- 识别稀树草原生态系统的基本部分：动物、植物、水、庇护所；
- 解释简单关系，比如"动物—食物""动物—水""动物—空间"；
- 用图片、箭头和标签共同做一张或一个生态系统图 / 模型。

## 4. 教师语言

教师输入：

- An ecosystem has living things and places.
- Animals need food, water, and space.
- What does this animal need?
- How are these connected?
- Use an arrow to show the connection.

幼儿可能回应：

- animal needs water
- zebra eats grass
- giraffe eats leaves
- connected / arrow / because
- drawing, labelling, explaining

## 5. 建议游戏与活动

### 活动 1：生态系统部件探究

**目的：**
用具体部件引入"生态系统"的想法。

**材料：**
动物、草、树、水、太阳、石头、阴凉、可以加"人 / 公园管理员"的卡；分类垫。

**准备：**
准备两到三张分类垫：生物、地点、需要。

**玩法 / 做法：**
幼儿把生态系统卡分类。讨论每一部分是怎么帮助动物生活的。教师引入简单连接："Grass helps zebra." "Trees help giraffe." "Water helps many animals."。

**教师提示：**
不要画复杂的食物网。K3 可以用箭头，但逻辑保持简单、看得见。

### 活动 2：连接箭头

**目的：**
帮助幼儿用视觉方式表示关系。

**材料：**
动物卡、需要卡、箭头卡、大板或地面垫。

**准备：**
动物卡放一边，需要 / 地点卡放另一边。

**玩法 / 做法：**
幼儿选一只动物，用箭头把它和一个需要连起来。再用一句短话解释："Elephant needs water." "Giraffe eats leaves."。

**教师提示：**
鼓励能力较强的幼儿试着用"because"。但不要每个人都要求完整句子。

### 活动 3：搭一个生态系统模型

**目的：**
把"关系"变成一个合作搭建的实体模型。

**材料：**
大底板、动物模型、纸草、树、蓝色布、标签、箭头、积木、小标牌。

**准备：**
把模型空间分成几个简单区：水、草原、树、休息处。

**玩法 / 做法：**
每个小组负责加一个区或一组动物。小组用箭头或标签表示一个关系。全班一起回顾这个模型。

**教师提示：**
可以分配角色：搭建者、放卡者、贴标签者、讲解者。这样小组合作更有秩序。
