# 肯尼亚 · K3 · 第 1 课
## 地图上的肯尼亚——稀树草原、山和水

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K3
- 课次：4 课中的第 1 课

## 2. 课程重点

K3 肯尼亚单元从"把肯尼亚当成一个由不同景观组成的地方"开始。幼儿用简单的地图、照片和模型材料，注意稀树草原、山、湖、河和受保护的野生动物区。重点是空间组织和景观词汇，不是记住详细的地理知识。

## 3. 学习目标

幼儿将：

- 在简单地图层面，认出肯尼亚是位于非洲的一个地方；
- 组织主要景观特征：稀树草原、山、湖、河；
- 用符号和材料搭建或标注一张简单的景观地图。

## 4. 教师语言

教师输入：

- Kenya is in Africa.
- This is a savanna.
- Here is a mountain / lake / river.
- What can we put on the map?
- How can we show water or grassland?

幼儿可能回应：

- Kenya / Africa
- savanna / mountain / lake / river
- put water here / animals here / grassland here
- labelling, placing, explaining

## 5. 建议游戏与活动

### 活动 1：简单地图引入

**目的：**
给 K3 幼儿一个清晰、符合年龄的空间背景来理解肯尼亚。

**材料：**
世界地图或地球仪、非洲地图、简单的肯尼亚轮廓图、贴纸、指物棒。

**准备：**
准备一层一层简化的地图：世界 → 非洲 → 肯尼亚。地图细节不要太多。

**玩法 / 做法：**
教师依次出示世界地图、非洲地图、肯尼亚地图。在肯尼亚上贴一张贴纸。讨论肯尼亚有城市、有人、有动物、有草原、有山、有湖、有河。幼儿轮流指一指或贴上图标。

**教师提示：**
不要测验幼儿的地图记忆。重点是"建立方位感"和"引起兴趣"。

### 活动 2：景观符号分类

**目的：**
在做地图前，先帮幼儿分类主要景观。

**材料：**
景观照片；稀树草原、山、湖、河、城市 / 保护区的符号卡；分类垫。

**准备：**
照片要清楚，图标要一一对应。

**玩法 / 做法：**
幼儿把照片分到不同的景观组里。问："Is this water?""Is this high or flat?""Where might animals find grass?"。幼儿把每张照片和对应符号配对。

**教师提示：**
用比较语言：高 / 矮、湿 / 干、开阔 / 封闭、平 / 突起。

### 活动 3：搭一张肯尼亚景观地图

**目的：**
把景观用视觉和空间方式表达出来。

**材料：**
大的肯尼亚轮廓图或空白地图底板、蓝色纸或布、绿色 / 黄色纸、棕色积木或纸山、标签、可重复使用的小钉。

**准备：**
把大底板放在桌上或地上。把符号和材料分到不同的托盘里。

**玩法 / 做法：**
幼儿在地图上加上水、草原、山、动物区域。放上标签或图标，并说出一个选择的原因："The river is blue." "Animals need grassland."。

**教师提示：**
地图可以是大致的形状。重点是"组织"和"解释"，不是"画得准"。
