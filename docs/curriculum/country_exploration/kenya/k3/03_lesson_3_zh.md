# 肯尼亚 · K3 · 第 3 课
## 动物移动和迁徙路线

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K3
- 课次：4 课中的第 3 课

## 2. 课程重点

幼儿通过简单的路线和地图符号来探索"动物在陆地上怎么移动"。他们学到：一些动物会移动，去找水、食物和更安全的地方。本课把"迁徙"作为想法引入，但不需要详细的科学术语或准确的路线。

## 3. 学习目标

幼儿将：

- 用路线、箭头和顺序语言表示动物移动；
- 用"为了食物""为了水""为了空间"这样的简单原因解释动物为什么移动；
- 画一张"路线图"或做一个"移动模型"，展示动物在景观中旅行的样子。

## 4. 教师语言

教师输入：

- Some animals move a long way.
- They move to find water and food.
- Start here. Go this way.
- Use arrows to show the route.
- Why do the animals move?

幼儿可能回应：

- to water / to food
- start / next / end
- they go together
- arrows, route, because

## 5. 建议游戏与活动

### 活动 1：用箭头讲"路线故事"

**目的：**
把"动物移动"引入为一种简单的"顺序"。

**材料：**
大景观垫、动物群卡、箭头卡、水 / 草 / 阴凉图标。

**准备：**
布置一条带起点、两个停点、终点的路线。

**玩法 / 做法：**
教师讲一个简单的路线故事："The zebras start here. They need water. They move this way."。幼儿贴上箭头，并按路线移动动物群卡。

**教师提示：**
路线保持短。重点是"为了需要而移动"，不是路线准确。

### 活动 2：设计一条迁徙路线

**目的：**
让幼儿独立或小组合作地组织移动路线。

**材料：**
空白路线地图、贴纸或卡片、箭头、马克笔、动物剪影。

**准备：**
准备简单的地图底板，陆地、水、草区域已经标好。

**玩法 / 做法：**
小组选一组动物，从一个地方画一条路线到另一个地方。加箭头和停靠点，再解释这条路线："First grass, next water, then rest."。

**教师提示：**
地图是"概念图"，不是"地理图"。重点是顺序和理由。

### 活动 3：身体地图移动

**目的：**
把地图路线和全身动作的理解连起来。

**材料：**
地面箭头、地点标志、动物头饰或动物卡。

**准备：**
在地上布置一条大路线，标好：草、水、树、休息。

**玩法 / 做法：**
幼儿作为"一群动物"沿路线走。每到一个停点，请一位幼儿解释为什么要停："Water." "Food." "Rest."。然后这组动物一起走向下一个箭头。

**教师提示：**
动作保持合作，不要变成比赛。教师可以带第一轮，后面的轮次让幼儿自己带。
