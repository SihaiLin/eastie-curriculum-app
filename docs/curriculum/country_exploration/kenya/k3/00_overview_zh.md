# 肯尼亚 · K3 概览

## 1. 国家特点

肯尼亚是一个很适合引导幼儿组织景观、野生动物、生活环境、动物移动和保护等想法的国家主题。它有清晰、幼儿看得见的关系：草原支持动物；动物需要水和空间；一些动物会成群移动；人们观察、保护、向自然学习。肯尼亚应当被当作一个"生态 + 探究式"的国家主题，而不是仅仅一份动物清单。

## 2. 年级视角

对 K3 来说，应当通过组织、解释、模型制作和展示来探索肯尼亚。幼儿可以使用简单的地图、类别、因果语言和项目中的角色，解释稀树草原的动物、土地、水、移动和保护是怎么连在一起的。核心视角是：**"我们怎么整理和解释一个肯尼亚稀树草原系统？"**

## 3. 教室布置与关键元素

教室可以布置一面"肯尼亚探究墙"：简单的地图轮廓、稀树草原生态图片、动物研究卡、水源地和迁徙路线图、望远镜或观察道具、野外记录模板、保护标语牌。材料应当能支持小组探究、做地图、做模型和做展示。

## 4. 四课地图

### 第 1 课：地图上的肯尼亚——稀树草原、山和水

幼儿在世界背景下定位肯尼亚，并组织主要的景观元素：稀树草原、山、湖、河和保护区。

### 第 2 课：稀树草原生态系统——动物、需要和关系

幼儿探索"动物和食物、水、庇护、空间、以及彼此之间"在简单生态系统里怎么连在一起。

### 第 3 课：动物移动和迁徙路线

幼儿用箭头、路线和简单的地图语言，表示动物为了找食物和水在陆地上移动的样子。

### 第 4 课：肯尼亚野生动物野外观察站

幼儿做一个迷你野外观察站或小博物馆，展示动物、生活环境、迁徙路线，以及人们保护野生动物的方式。
