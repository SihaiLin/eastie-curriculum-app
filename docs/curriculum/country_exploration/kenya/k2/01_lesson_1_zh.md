# 肯尼亚 · K2 · 第 1 课
## 稀树草原动物——相同和不同

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K2
- 课次：4 课中的第 1 课

## 2. 课程重点

幼儿通过稀树草原动物和"比较看得见的特征"来认识肯尼亚。重点不是记住动物知识，而是注意相同和不同：长脖子、长鼻子、条纹、斑点、鬃毛、大身体、小身体、快跑、慢走。

## 3. 学习目标

幼儿将：

- 通过可见特征和动作来比较多几种肯尼亚稀树草原动物；
- 用"大 / 小""条纹 / 斑点""走 / 跑"这样的简单类别给动物卡分类；
- 用短句、手势或摆放选择来解释相同和不同。

## 4. 教师语言

教师输入：

- What is the same?
- What is different?
- This animal has stripes.
- This animal has a long neck.
- Put the big animals here.

幼儿可能回应：

- same / different
- big elephant / tall giraffe / zebra stripes
- sorting, matching, pointing, short phrases

## 5. 建议游戏与活动

### 活动 1：动物特征圆圈

**目的：**
在分类之前，先帮助幼儿注意动物看得见的特征。

**材料：**
大幅动物卡：长颈鹿、斑马、大象、狮子、猎豹、鸵鸟；特征卡：条纹、斑点、长脖子、长鼻子、鬃毛。

**准备：**
把动物卡围成一个圈，特征卡放在小篮子里。

**玩法 / 做法：**
幼儿选一张特征卡，放到对应的动物旁边。教师用简单比较问题问："Who has stripes?""Who is tall?""Who has a trunk?"。

**教师提示：**
尽量用真实照片或写实的图。K2 在图片清晰的时候能比较得更准确。

### 活动 2：相同 / 不同分类垫

**目的：**
用适合幼儿的类别练习分类。

**材料：**
标了图标的分类垫、动物卡、篮子。

**准备：**
准备两到三对简单类别：大 / 小、条纹 / 斑点、走 / 跑。

**玩法 / 做法：**
幼儿把动物卡分到对应的垫上。分完后，请他们说一说自己的一个选择："Zebra here — stripes." "Elephant here — big."。

**教师提示：**
一次不要用太多类别。等幼儿理解了第一条规则，再换下一条。

### 活动 3：动物比较线

**目的：**
让"比较"变成可以动手、合作的活动。

**材料：**
动物卡、地面线、夹子或立式卡架。

**准备：**
在地上画或贴一条简单的线。一边可以是"高"，另一边是"矮"；或者一边是"快"，另一边是"慢"。

**玩法 / 做法：**
幼儿按教师提示把动物卡沿线放好。比如长颈鹿靠近"高"，狮子或猎豹靠近"快"，大象靠近"大"。放完后简单讨论一下。

**教师提示：**
接受"大致合理"的判断。重点是表达和比较，不是科学地给动物排名。
