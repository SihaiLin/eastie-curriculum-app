# 肯尼亚 · K2 · 第 4 课
## 肯尼亚稀树草原分类地图

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K2
- 课次：4 课中的第 4 课

## 2. 课程重点

幼儿把对肯尼亚的探索内容组织到一张合作的"稀树草原分类地图"上。地图包含动物、特征、需要、生活环境和移动路径。重点是分类和简单解释，不是地理准确。

## 3. 学习目标

幼儿将：

- 把肯尼亚的动物和环境材料清楚地分到同一张地图上；
- 用"动物—特征""动物—需要""动物—地点"等简单关系；
- 通过摆放、指出或解释自己负责的那部分，参与一次小组回顾。

## 4. 教师语言

教师输入：

- Let’s make a savanna map.
- Put animals here.
- Put water here.
- Which animals have stripes?
- Show me one animal and one place.

幼儿可能回应：

- zebra has stripes
- elephant needs water
- giraffe by tree
- sorting, grouping, pointing, short explanation

## 5. 建议游戏与活动

### 活动 1：先分类再搭建

**目的：**
在做最终地图前，先帮幼儿把材料分好。

**材料：**
动物卡、特征卡、需要卡、生活环境卡、篮子或托盘。

**准备：**
把分类篮摆好，标上简单图标：动物、图案、需要、地点。

**玩法 / 做法：**
幼儿把材料分到篮子里。教师用简单问题检查分类："Is this an animal?""Is this water?""Does this show stripes?"。

**教师提示：**
这样能让最终展示更清楚，避免幼儿乱放。

### 活动 2：搭一张稀树草原地图

**目的：**
把 K2 单元的内容共同整理成一张可视的图。

**材料：**
大纸或布底板、蓝色纸做水、绿色 / 黄色 / 棕色纸、动物卡、箭头、胶水或可重复使用的小钉。

**准备：**
准备一张大底板，留出足够空间放水、草、树和动物组。

**玩法 / 做法：**
幼儿先放景观材料，再放动物，最后加箭头或特征标签。教师支持简单推理："Zebra near grass." "Animals go to water." "Stripes group here."。

**教师提示：**
地图应当能看出"关系"，不只是装饰。可以问幼儿"为什么放在这里"，但接受短回答。

### 活动 3：我知道的一点点

**目的：**
给幼儿一个简单的方式分享本单元的理解。

**材料：**
完成的稀树草原地图、指物棒、动物卡。

**准备：**
把幼儿围成小组，围在地图周围。

**玩法 / 做法：**
每位幼儿选一样东西来展示：一种动物、一种需要、一个地点、或一条路径。教师帮他说或演示一句："Zebra has stripes." "Elephant needs water." "Animals go together."。

**教师提示：**
可以个别分享，也可以两两分享。不要把它变成正式汇报。
