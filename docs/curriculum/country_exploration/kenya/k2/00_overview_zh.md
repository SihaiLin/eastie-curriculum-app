# 肯尼亚 · K2 概览

## 1. 国家特点

肯尼亚是一个很强的"自然与野生动物"国家主题。对幼儿最容易接触的内容是开阔的稀树草原、动物群体、动物的移动、迁徙、图案，以及动物和它们生活环境的关系。肯尼亚不能被简化成"很多动物"。它应当帮助幼儿注意到：草原动物怎么生活、怎么动、怎么成群、怎么依赖环境。

## 2. 年级视角

对 K2 来说，应当通过分类、比较、匹配和建立简单关系来认识肯尼亚。幼儿可以比较动物的身体特征，按动作或生活环境给动物分组，把动物和水、草、树连起来，并理解"动物在草原上移动"的一个简单版本。核心视角是：**"动物有哪些不同？它们需要什么？它们会往哪里移动？"**

## 3. 教室布置与关键元素

教室可以布置一面"肯尼亚稀树草原板"：动物群、生活环境分区、水源地图片、草原颜色、动物足迹、迁徙箭头、图案样本和分类篮。K2 的材料应当能邀请"分类和比较"：动物卡、生活环境卡、动作卡、大小卡、脚印卡和小世界地图。

## 4. 四课地图

### 第 1 课：稀树草原动物——相同和不同

幼儿按大小、身体部分、图案和动作来比较多见的稀树草原动物：长颈鹿、斑马、大象、狮子等。

### 第 2 课：动物的家和需要

幼儿把动物和草、树、水、阴凉、休息处连起来。他们搭建简单的生活环境场景，并把动物和"它们需要什么"配在一起。

### 第 3 课：在草原上移动

幼儿通过路径、箭头、水源地和"一起移动"来认识动物的移动和迁徙的一个简单版本。

### 第 4 课：肯尼亚稀树草原分类地图

幼儿做出一张合作地图，把动物、需要、图案和移动路径组织到同一个肯尼亚稀树草原展示里。
