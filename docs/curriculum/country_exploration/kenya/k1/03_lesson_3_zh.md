# 肯尼亚 · K1 · 第 3 课
## 颜色、图案和触感

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K1
- 课次：4 课中的第 3 课

## 2. 课程重点

幼儿通过动物图案、草原颜色和有质感的材料来探索肯尼亚。他们注意条纹、斑点、粗糙、光滑、柔软、棕色、黄色、绿色，以及黑白对比，然后做一幅简单的图案拼贴。

## 3. 学习目标

幼儿将：

- 注意到动物图片上看得见的图案，比如条纹和斑点；
- 通过触摸、选择和摆放来探索颜色和质感材料；
- 在教师支持下，做一幅简单的、受肯尼亚启发的拼贴。

## 4. 教师语言

教师输入：

- I see stripes.
- I see spots.
- Touch gently. Is it soft or rough?
- Choose a colour.
- Put it here.

幼儿可能回应：

- stripes / spots
- soft / rough
- black / white / yellow / brown / green
- choosing, touching, placing, gluing

## 5. 建议游戏与活动

### 活动 1：找条纹，找斑点

**目的：**
帮助幼儿在视觉上注意动物的图案。

**材料：**
斑马、长颈鹿、豹子等动物图片；印有条纹和斑点的图案卡。

**准备：**
把动物图片和简单图案卡放在桌上或墙上。

**玩法 / 做法：**
幼儿找条纹和斑点。把一张条纹卡放到斑马图旁，把一张斑点卡放到长颈鹿或豹子图旁。教师重复简单语言："stripes""spots""same""look"。

**教师提示：**
整套材料保持少量。图案太多会让 K1 觉得视觉过载。

### 活动 2：触感小篮

**目的：**
给幼儿一个"用身体感觉"进入肯尼亚主题的机会。

**材料：**
布头、毛毡、有质感的纸、光滑卡纸、棕 / 黄 / 绿色纸、篮子。

**准备：**
把安全、有质感的材料分到几个篮子里。避免容易脱落、可能被误吞的小零件。

**玩法 / 做法：**
幼儿摸一摸、选一选。教师说出简单的质感词：soft、rough、smooth。幼儿按颜色分组，或者把自己最喜欢的质感放到垫子上。

**教师提示：**
这是"触感探索"环节，还没到做作品的阶段。允许幼儿先玩一玩，再开始粘贴。

### 活动 3：肯尼亚图案拼贴

**目的：**
为肯尼亚展示做出一件幼儿自己做的小视觉作品。

**材料：**
A4 或 A3 纸、预剪好的纸条、圆点或斑点、有质感的纸、胶棒、如有需要可以准备动物轮廓模板。

**准备：**
准备简单的拼贴材料，颜色限制在：黑、白、黄、棕、绿。

**玩法 / 做法：**
幼儿选纸条、斑点、质感纸，在纸上摆放。可以做斑马图案、长颈鹿斑点，或一个抽象的草原图案。教师在摆放和粘贴时给支持。

**教师提示：**
不要把幼儿往"画得逼真"的方向纠正。重点是"注意到了"和"做出来了"，不是准确还原。
