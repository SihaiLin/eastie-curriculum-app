# 肯尼亚 · K1 · 第 2 课
## 动物的动和脚印

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K1
- 课次：4 课中的第 2 课

## 2. 课程重点

幼儿通过大动作游戏、匹配和简单的假装探索，认识动物怎么动、可能留下什么样的脚印。本课把动物和"它们怎么动、走过哪里、留下什么痕迹"连起来。

## 3. 学习目标

幼儿将：

- 模仿安全的动物动作，比如踏、伸、走、踮脚、安静休息；
- 把简单的脚印形状和熟悉的肯尼亚动物图片匹配起来；
- 在教师支持和明确边界的前提下，参与一次集体动作游戏。

## 4. 教师语言

教师输入：

- Walk slowly.
- Stomp like an elephant.
- Stretch tall like a giraffe.
- Look, footprints!
- Which animal made this footprint?

幼儿可能回应：

- elephant / giraffe / zebra / lion
- stomp / walk / tall
- matching, pointing, stepping, copying movement

## 5. 建议游戏与活动

### 活动 1：脚印小径

**目的：**
帮助幼儿注意到：动物会在地上走过，并可能留下脚印。

**材料：**
大幅覆膜的脚印卡、动物卡、胶带、地面空间。

**准备：**
在地面上用脚印卡铺一条简单的"脚印小径"，小径终点放一张动物卡。

**玩法 / 做法：**
幼儿沿着脚印慢慢走。走到终点时，找到动物卡，说一说、指出或模仿这只动物。再换一种脚印大小或形状重复。

**教师提示：**
脚印不需要画得很"科学"，能提示幼儿"走 + 匹配"就够了。

### 活动 2：动起来——定格

**目的：**
在练习动作控制的同时，把动物和动作词连起来。

**材料：**
动物卡、鼓或沙锤、开阔的动作区。

**准备：**
清理地面，标好动作范围。

**玩法 / 做法：**
教师出示动物卡并给一个动作提示。鼓或沙锤响起时，幼儿做动作。声音一停，所有人像那只动物一样"定格"。

**教师提示：**
音量柔和，"开始—停"节奏要稳定。目标是身体控制，不是比快。

### 活动 3：动物回家路径匹配

**目的：**
把"动作""动物"和"草原里的简单地点"连起来。

**材料：**
小动物模型、脚卡、纸树、纸草、石块、垫子。

**准备：**
在一片小草原垫上设几个简单目的地：树、草、石头、休息处。

**玩法 / 做法：**
幼儿选一种动物，让它沿着脚印小径走到一个地方。教师用语言叙述："The giraffe walks to the tree." "The elephant walks to the water."。幼儿可以重复一个词、指出或直接把动物放过去。

**教师提示：**
K1 不要求"对的生活环境知识"。重点是"小心操作材料"和"动作—语言"的简单连接。
