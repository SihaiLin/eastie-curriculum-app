# 肯尼亚 · K1 · 第 1 课
## 认识肯尼亚——草原和大型动物

## 1. 课程身份

- 国家 / 地区：肯尼亚
- 年级：K1
- 课次：4 课中的第 1 课

## 2. 课程重点

幼儿通过大幅草原图片和标志性的动物认识肯尼亚。重点是具体的观察：大 / 小、高 / 矮、快 / 慢、条纹 / 斑点，以及动物的动作。幼儿不需要记住关于国家的知识；他们应当把肯尼亚体验成"一个温暖、开阔、有动物和大自然的地方"。

## 3. 学习目标

幼儿将：

- 注意到几种和肯尼亚常见联系在一起的大型动物，比如长颈鹿、斑马、大象、狮子；
- 用指、选择、动作或一个词对动物图片做出反应；
- 用图片、道具和动物模型共同参与一个简单的肯尼亚发现角。

## 4. 教师语言

教师输入：

- Look, this is Kenya.
- I see grass. I see animals.
- This animal is tall / big / fast / slow.
- Can you point to the zebra?
- Move like a giraffe. Walk slowly.

幼儿可能回应：

- zebra / lion / elephant / giraffe
- big / tall / fast
- pointing, choosing, moving, placing animals

## 5. 建议游戏与活动

### 活动 1：大图片漫步

**目的：**
帮助幼儿通过大幅、清晰的视觉图片进入肯尼亚主题。

**材料：**
大幅打印或投影的草原图片、动物图片卡、地面标记或垫子。

**准备：**
把图片贴在教室幼儿视线高度。把动物卡放在和对应草原图附近的位置。

**玩法 / 做法：**
请幼儿和教师一起慢慢绕教室走。停在每张图前，说一说看到的东西：草、天空、树、动物。请幼儿指出一种动物、轻轻摸一摸图片、或站到最喜欢的图旁边。

**教师提示：**
节奏保持慢。K1 幼儿不需要用句子回应。用手指、走向图片都是有效的回应。

### 活动 2：动物大小和动作

**目的：**
把"认出动物"和"身体动作"连起来。

**材料：**
动物卡或动物玩具：长颈鹿、斑马、大象、狮子；空地。

**准备：**
在动作区中间放一张动物卡。

**玩法 / 做法：**
出示一种动物，示范一个简单动作：像长颈鹿一样伸长身体、像大象一样慢慢踏步、像斑马一样有节奏地走、像狮子一样安静休息。幼儿跟着做，再选下一张动物卡。

**教师提示：**
避免追跑或"狮子"类剧烈游戏。动物动作保持受控、好玩、安全。

### 活动 3：肯尼亚动物角

**目的：**
让幼儿操作具体材料，开始搭建一个共同的"主题角"。

**材料：**
小世界动物、棕 / 绿 / 黄布、纸草、篮子、积木、动物卡。

**准备：**
用一张小桌子或地垫布置一个"肯尼亚发现角"。

**玩法 / 做法：**
请幼儿把动物放到草原垫上。教师鼓励他们想一想：长颈鹿、斑马、大象或狮子应该站在哪里。再用纸草和积木加几棵"树"或几块"石头"。

**教师提示：**
这个活动可以在本周内一直作为"区角"开放。把幼儿的摆放拍下来，之后可以做展示。
