# 肯尼亚 · K1 概览

## 1. 国家特点

肯尼亚是一个色彩鲜明、视觉感很强的国家主题，特别适合幼儿。可以从开阔的草原、大型动物、暖色、简单的动作、鼓点、图案和户外探索的角度来介绍。对 K1 幼儿来说，肯尼亚不应被讲成一份厚厚的地理知识课。更好的方式是一次"遇见大型动物、感受开阔空间、模仿动物动作、注意自然颜色、共同动手做"的体验。

## 2. 年级视角

对 K1 来说，应当通过感官体验、视觉辨认、动作游戏和假装游戏来认识肯尼亚。幼儿看大型动物图片、模仿动物动作、触摸有质感的材料、搭建简单的草原场景，并做出大色块图案作品。核心视角是：**"我们能看到哪些动物？它们怎么动？我们可以注意到哪些颜色和图案？"**

## 3. 教室布置与关键元素

教室可以布置一个"肯尼亚发现角"：草原图片、大型动物卡、棕绿黄色布料、动物脚印、简单的鼓或沙锤、图案条、篮子、积木和小世界动物。布置应当让人感到开阔、自然。大幅图片和具体的道具比地图或文字信息更有用。

## 4. 四课地图

### 第 1 课：认识肯尼亚——草原和大型动物

幼儿通过开阔的草原图片和大型动物进入肯尼亚主题——长颈鹿、斑马、大象、狮子。他们注意大小、颜色、动作和简单的动物特征。

### 第 2 课：动物的动和脚印

幼儿探索动物怎么动、可能留下什么样的脚印。他们爬、踏、伸长、踮脚，并把简单的脚印形状和动物图片匹配起来。

### 第 3 课：颜色、图案和触感

幼儿仔细看斑马条纹、长颈鹿斑点、动物皮毛的质感、草原的颜色，以及简单的图案材料。他们做出一幅受肯尼亚启发的大色块拼贴。

### 第 4 课：搭建一座迷你肯尼亚草原

幼儿用积木、布、纸草、动物和之前做的作品，共同搭出一片小草原，展示动物可以站立、移动、躲藏或休息的地方。
