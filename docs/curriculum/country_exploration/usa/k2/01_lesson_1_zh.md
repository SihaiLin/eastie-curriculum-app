# 美国 · K2 · 第 1 课
## 美国符号——匹配和分类

## 1. 课程身份

- 国家 / 地区：美国
- 年级：K2
- 课次：4 课中的第 1 课

## 2. 课程重点

幼儿通过匹配、分类和比较，认识美国城市符号：地标、建筑、出租车、桥梁和国旗颜色。

## 3. 学习目标

幼儿将：

- 认出几个具体的美国城市和地标元素；
- 按简单类别（地标、交通、建筑、颜色）给图片分类；
- 用短句比较"高 / 矮""大 / 小""相同 / 不同"，描述或选择国家元素。

## 4. 教师语言

教师输入：

- What can you see?
- This is a landmark.
- This is a taxi.
- This building is tall.
- Are they the same or different?
- Put the taxi with transport.
- Put the statue with landmarks.
- Which one is taller?

幼儿可能回应：

- taxi / building / bridge / statue
- same / different
- tall / short / big
- I see a taxi.
- It is tall.
- This is a bridge.

## 5. 建议游戏与活动

### 活动 1：美国符号匹配

**目的：**
帮助幼儿认出并匹配具体的美国符号。

**材料：**
成对的图片卡：自由女神像、黄色出租车、城市天际线、金门大桥、汉堡、篮球、美国国旗颜色。

**准备：**
每张图准备两份。一份贴在墙上或板上，另一份放在篮子里。

**玩法 / 做法：**
幼儿从篮子里选一张卡，再在墙上找到相同的图。匹配之后，教师问一个简单的注意性问题："Is it tall?""Is it a car?""Is it a bridge?"。

**教师提示：**
匹配组先少一些。如果班级很有信心，再增加卡片。

### 活动 2：把美国分类放好

**目的：**
支持 K2 的分类和归类思考。

**材料：**
图片卡和四个分类托盘：地标、交通、建筑、食物 / 运动。

**准备：**
在托盘上贴文字和图标。桌上放混在一起的图片。

**玩法 / 做法：**
幼儿把图片分类放进托盘。教师示范一两张："Taxi — transport""Statue — landmark"。幼儿继续，两人或小组一起做。分类完成后一起回顾每个托盘。

**教师提示：**
如果幼儿对某个归类有争议，不用急。把它当作一次"比较"的机会。

### 活动 3：高高的城市，长长的桥

**目的：**
把美国城市图片和简单的比较、搭建连起来。

**材料：**
积木、乐高、桥梁图片、城市天际线图片、马路片段或胶带、玩具车。

**准备：**
布置一个建筑区和一个桥 / 马路区。

**玩法 / 做法：**
幼儿搭高建筑和一座长长的桥或马路。教师请他们做比较："Which is taller?""Which is longer?""Where can the taxi go?"。在城市和桥的模型旁边放对应的图片卡。

**教师提示：**
K2 幼儿可以开始使用比较语言，但重点还是"搭起来"和"看到不同"，不是正式测量。
