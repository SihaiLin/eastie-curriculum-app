# 美国 · K2 概览

## 1. 国家特点

美国是一个现代、辨识度很高的国家主题。可以从大城市、著名地标、流行食物、运动、日常生活中的视觉文化和明亮的重复图像来介绍美国。对幼儿来说，美国有许多具体的切入点：自由女神像、高高的城市建筑、黄色出租车、汉堡、爆米花、篮球、棒球、桥梁和 Pop Art 波普艺术风格的图像。

美国很适合作为国家主题，因为它可以让幼儿把日常生活中可能已经见过的东西和"世界上更远的一个地方"连起来。教学时不要把它主要当成地图或知识记忆单元；更有效的处理方式是把它作为"城市符号、熟悉的全球物品、视觉文化、运动、现代生活"这样一个主题。

## 2. 年级视角

K2 幼儿通过分类、比较、匹配和建立简单联系来认识美国。核心视角是：**"什么是相同的，什么是不同的，这些东西是怎么归在一起的？"**

K2 幼儿可以比较高楼和矮建筑、把地标和城市场景匹配、把食物和运动图片分类、注意波普艺术里重复出现的规律，并在城市生活、食物文化和视觉符号之间建立简单的联系。他们可以说短句、表达简单的喜欢与否、运用基础比较语言，但国家主题仍然要保持具体、保持活动化。

## 3. 教室布置与关键元素

教室可以布置一面"美国发现墙"，分成几个清晰的区域：城市与地标、食物与生活、运动与动作、Pop Art 色彩。教师可以展示大幅视觉：自由女神像、纽约风格的城市天际线、金门大桥、黄色出租车、汉堡、爆米花、篮球、棒球，以及重复出现的彩色图像。

对 K2 来说，材料应当能邀请"分类和比较"：图片卡、匹配组、分类篮、搭建材料、马路片段、食物卡、运动卡和重复图像模板。

关键元素：自由女神像 / 城市天际线 / 金门大桥 / 黄色出租车 / 汉堡 / 爆米花 / 篮球 / 棒球 / Pop Art 波普艺术

## 4. 四课地图

### 第 1 课：美国符号——匹配和分类

幼儿认识美国城市符号，并把它们分成简单的组：建筑、交通、地标、颜色和城市物品。他们比较高矮、大小和相同 / 不同。

### 第 2 课：食物、运动和日常生活

幼儿通过分类、选择和角色扮演，认识熟悉的美国相关食物和运动。他们比较不同的食物、连运动和器材，并说自己喜欢什么。

### 第 3 课：波普艺术工作室——重复、变化、比较

幼儿探索重复图像和明亮的颜色。他们创作波普艺术风格的作品，同时注意相同 / 不同、重复的规律和颜色的变化。

### 第 4 课：制作一面美国发现板

幼儿把单元内容组织成一面班级发现板，分为城市、地标、食物、运动、艺术等类别。他们选择图片、分类、摆放，并分享一个发现。
