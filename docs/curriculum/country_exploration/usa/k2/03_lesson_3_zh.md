# 美国 · K2 · 第 3 课
## 波普艺术工作室——重复、变化、比较

## 1. 课程身份

- 国家 / 地区：美国
- 年级：K2
- 课次：4 课中的第 3 课

## 2. 课程重点

幼儿通过创作"颜色不同、但图形重复"的图像来探索波普艺术风格的重复，然后比较"什么一样、什么不一样"。

## 3. 学习目标

幼儿将：

- 注意视觉图像中的重复、颜色变化和相同 / 不同；
- 用熟悉的美国元素创作重复图像；
- 和同伴或小组比较自己的重复图像，为班级展示做准备。

## 4. 教师语言

教师输入：

- Same picture, different colours.
- What is the same?
- What is different?
- Repeat the picture.
- Change the colour.
- Put four pictures together.
- Which colour do you like?

幼儿可能回应：

- same / different
- repeat
- red / blue / yellow / green
- taxi / hamburger / building
- I like red.
- It is different.

## 5. 建议游戏与活动

### 活动 1：相同和不同的波普图像

**目的：**
在自己动手之前，先帮助幼儿理解"重复"和"变化"。

**材料：**
教师自制的重复图像样张：出租车、汉堡、建筑、星星、篮球。

**准备：**
准备两份样张：一份"图形一样、颜色也一样"，另一份"图形一样、颜色不同"。

**玩法 / 做法：**
出示样张，请幼儿说说"什么是相同的、什么是不同的"。幼儿指出重复的物品、重复的颜色和变化了的颜色。教师用简单比较语言。

**教师提示：**
不要详细讲艺术史。对 K2 来说，波普艺术主要是一条进入"重复、颜色、视觉比较"的路径。

### 活动 2：四格波普艺术

**目的：**
让幼儿做一件简单的重复图像作品。

**材料：**
四格纸模板、印章或预剪图、马克笔、蜡笔、胶水、彩色纸。

**准备：**
准备画好四个格子的模板。每次只提供两到三种图。

**玩法 / 做法：**
幼儿选一种图，在四个格子里重复。每次可以换一种颜色、背景或图案。教师用提示支持："Same taxi, different colour""Repeat again"。

**教师提示：**
K2 幼儿可以自己做一些选择，但可能需要帮助——在四个格子里保持用同一种图。

### 活动 3：波普艺术两人比较

**目的：**
用简单方式鼓励幼儿比较和分享作品。

**材料：**
完成好的四格作品、展示板、便利贴或小贴纸。

**准备：**
把幼儿两两配对或分成小组。准备一块展示区。

**玩法 / 做法：**
幼儿和自己的同伴比较作品，找一样的地方和不一样的地方。然后把作品贴到班级美国艺术展示板上。

**教师提示：**
需要时用句型框架支持幼儿："Same colour""Different taxi""I like blue"。
