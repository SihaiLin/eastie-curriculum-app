# 美国 · K2 · 第 2 课
## 食物、运动和日常生活

## 1. 课程身份

- 国家 / 地区：美国
- 年级：K2
- 课次：4 课中的第 2 课

## 2. 课程重点

幼儿通过分类、匹配、比较和简单的角色扮演，认识熟悉的美国相关食物和运动。

## 3. 学习目标

幼儿将：

- 识别与美国流行文化有关的食物和运动元素；
- 按简单特征给食物和运动图片分类；
- 把运动和器材或动作匹配，并用词、手势或短句表达简单的偏好。

## 4. 教师语言

教师输入：

- What food can you see?
- Do you like hamburgers?
- Put the food here.
- Put the sports here.
- This is basketball.
- What do we need for baseball?
- Same or different?
- Which one do you like?

幼儿可能回应：

- hamburger / popcorn / fries
- basketball / baseball
- I like basketball.
- I like hamburgers.
- food / sport
- same / different

## 5. 建议游戏与活动

### 活动 1：食物还是运动？

**目的：**
帮助幼儿把熟悉的美国相关图片分成有意义的组。

**材料：**
食物卡：汉堡、薯条、热狗、爆米花、饮料。运动卡：篮球、棒球、橄榄球、球、球棒、篮筐。

**准备：**
准备两张大的分类垫：食物、运动。用图标帮助不识字的幼儿。

**玩法 / 做法：**
幼儿轮流选一张卡，放到正确的垫上。每次放完，教师问一个简单追问："Do you like it?""Can you play it?""Is it food?"。

**教师提示：**
美式橄榄球可以选做；篮球和棒球对幼儿更容易理解，也更容易演一演。

### 活动 2：美国小食店

**目的：**
用食物道具做社交角色扮演、选择和表达偏好。

**材料：**
玩具食物或纸做的食物、托盘、盘子、杯子、店招、可以加一个带图片的仿真菜单。

**准备：**
布置一个有两到三种食物选择的小食店。

**玩法 / 做法：**
幼儿从图片菜单上选一种食物，放到托盘上。教师示范："A hamburger, please""Here you are""Thank you""I like popcorn"。幼儿可以轮流当"店员"和"顾客"。

**教师提示：**
这是角色扮演，不是真吃。如果用真食物，要先确认学校政策和过敏情况。

### 活动 3：篮球和棒球动作

**目的：**
把美国运动和动作、动作词、简单的器材匹配连起来。

**材料：**
软球、篮筐或球框、棒球棒图片、棒球手套图片、运动卡、锥形桶。

**准备：**
布置一个安全的活动区。只用软球。

**玩法 / 做法：**
出示运动卡，演一些简单动作：拍、扔、接、打、跑。幼儿把运动卡和动作或物品匹配起来。然后做一次简单的篮球投掷或棒球式的假装挥棒，不使用硬器材。

**教师提示：**
安全和轮流第一。重点是"动起来"和"认出来"，不是运动技能训练。
