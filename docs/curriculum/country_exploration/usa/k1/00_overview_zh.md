# 美国 · K1 概览

## 1. 国家特点

美国是一个现代、视觉感强、孩子们很熟悉的国家主题。可以从大城市、高楼、著名地标、食物、运动和强烈的流行文化图像来介绍美国。有些孩子可能已经在生活中见过和"美国"有关的元素，比如汉堡、爆米花、篮球、黄色出租车、可口可乐风格的产品图像、卡通或超级英雄形象。

对 K1 幼儿来说，美国应当是一个明亮、热闹、充满"可以看、可以动、可以搭、可以假装、可以用颜色做出来"的东西的地方。最有力量的切入点不是关于这个国家的知识，而是具体的图像：高高的城市、黄色出租车、一座大雕像、一个汉堡、一颗篮球，以及一组重复出现的彩色图片。

## 2. 年级视角

K1 幼儿通过直接的视觉、感官、动作和游戏化体验来认识美国。他们不需要记住关于这个国家的知识、城市名称或复杂的文化信息。核心视角是：**"我们能看到什么、摸到什么、可以动什么、可以假装什么、可以做出来什么？"**

K1 的美国单元应当聚焦在注意形状、颜色、大小、动作、食物道具和熟悉的现代符号。幼儿可以通过指、选、匹配、动、搭、贴、画来回应，也可以说一个词或一句很短的话。口头表达保持可选、保持轻量。

## 3. 教室布置与关键元素

教室可以布置一个简单的美国角：大幅城市天际线图片、自由女神像、黄色出租车、高楼建筑、红白蓝色调元素、汉堡或爆米花道具、篮球图片，以及明亮的 Pop Art 波普艺术风格重复图片。布置应当让人感到好玩、具体，而不是信息性。

对 K1 来说，大幅图片、玩具车、积木、食物道具、颜色卡、简单公路垫和重复图案模板，比地图、长篇文字或抽象解释更有用。

关键元素：自由女神像 / 高楼 / 黄色出租车 / 汉堡 / 爆米花 / 篮球 / Pop Art 波普艺术 / 红白蓝

## 4. 四课地图

### 第 1 课：认识美国——大城市与标志

幼儿通过大幅城市图片、高楼、黄色出租车和自由女神像认识美国。他们注意颜色、形状、大小和动作，然后搭建或摆放一个简单的城市场景。

### 第 2 课：美国食物和日常生活中的流行文化

幼儿通过假装游戏、分类、匹配和简单的角色扮演，认识熟悉的美国食物和日常流行文化元素：汉堡、薯条、爆米花、饮料和类似产品的视觉。

### 第 3 课：Pop Art 波普艺术的色彩和重复

幼儿看明亮的重复图像和强烈的颜色，然后用熟悉的美国元素做出一件简单的波普艺术风格作品：重复的形状、食物图像、出租车或城市符号。

### 第 4 课：搭建和分享一座迷你美国城市

幼儿把 K1 美国单元的体验汇集成一座小型的"美国城市"展示：积木、马路、出租车、地标卡、食物角和幼儿的波普艺术作品。他们可以指出或分享自己做的一样喜欢的东西。
