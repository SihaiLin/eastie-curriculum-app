# 美国 · K1 · 第 3 课
## Pop Art 波普艺术的色彩和重复

## 1. 课程身份

- 国家 / 地区：美国
- 年级：K1
- 课次：4 课中的第 3 课

## 2. 课程重点

幼儿探索明亮的颜色和重复出现的图像，灵感来自美国的波普艺术，然后用熟悉的美国元素做出简单的重复图像作品。

## 3. 学习目标

幼儿将：

- 注意重复图像、明亮的颜色和简单的视觉规律；
- 用盖章、涂色、粘贴或摆放的方式做出重复图像；
- 把熟悉的美国相关物品和一次艺术活动连起来，参与到一次共同的视觉展示中。

## 4. 教师语言

教师输入：

- Look at the colours.
- Same picture, different colours.
- Red, blue, yellow, green.
- Again, again, again.
- Let’s make a picture.
- Put it here.
- It is bright.

幼儿可能回应：

- red
- blue
- yellow
- same
- again
- bright
- taxi
- hamburger

## 5. 建议游戏与活动

### 活动 1：一样的图，不一样的颜色

**目的：**
用一种 K1 容易接受的方式，引入"重复"和"颜色变化"。

**材料：**
教师自制的样张：同一个简单图像重复出现，但颜色不同，比如出租车、汉堡、星星、建筑或饮料瓶形状。

**准备：**
准备 2–3 张重复图像样张。避免过复杂的作品。

**玩法 / 做法：**
给幼儿看这些重复图像。教师指着图说"Same picture"，再指着颜色说"different colours"。请幼儿找相同 / 不同、指颜色、选他们最喜欢的那一张。

**教师提示：**
不要讲艺术史。"Pop Art"可以是教师心中的概念；面向幼儿时，重点是相同 / 不同、颜色和重复。

### 活动 2：美国图像盖章

**目的：**
让幼儿通过盖章或粘贴，做出重复的视觉图案。

**材料：**
泡沫印章、海绵印章、贴纸，或者预剪好的出租车、建筑、汉堡、星星、圆形；大纸；颜料或印台。

**准备：**
准备一张大的集体纸或每人一张小纸。印章形状只提供两到三种。

**玩法 / 做法：**
幼儿用同一个印章盖很多次。可以每次换一种颜色，也可以只用一种颜色。教师示范："Again""same""red taxi""blue taxi"。幼儿把盖出来的重复图加到一面共同设立的"美国波普艺术墙"上。

**教师提示：**
K1 重点是过程而不是干净的图案。有的幼儿可能只盖一两次，这是可以接受的。

### 活动 3：明亮图片画廊漫步

**目的：**
用简单的画廊式常规，让幼儿注意并分享自己的作品。

**材料：**
幼儿完成的作品、展示墙或地面画廊、小贴纸（用来选最喜欢的图）。

**准备：**
把作品展示在幼儿视线高度。留出可以安全行走的空间。

**玩法 / 做法：**
幼儿慢慢在画廊里走动。他们指出颜色、形状和重复图像。每位幼儿可以在自己喜欢的图旁边贴一张小贴纸，或指一指自己的作品。教师用简单回顾语言："I see a taxi""I see red""same picture"。

**教师提示：**
不要给幼儿作品排名。重点是共同的注意和自信，不是艺术评判。
