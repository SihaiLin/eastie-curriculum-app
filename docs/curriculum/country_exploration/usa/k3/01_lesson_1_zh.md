# 美国 · K3 · 第 1 课
## 美国在哪里？城市、地图与地标

## 1. 课程身份

- 国家 / 地区：美国
- 年级：K3
- 课次：4 课中的第 1 课

## 2. 课程重点

幼儿通过简单的世界地图背景认识美国，然后把主要的城市、地标、交通和符号图片按类别组织起来。

## 3. 学习目标

幼儿将：

- 在简单的地图层面，理解美国是位于北美洲的一个大国；
- 识别几个有辨识度的美国符号：自由女神像、城市天际线、桥梁和黄色出租车；
- 把图片按类别组织起来，开始为之后的小指南或小博物馆准备信息。

## 4. 教师语言

教师输入：

- This is the USA.
- The USA is in North America.
- What can you see in this city?
- This is a landmark.
- Let’s sort the pictures.
- Which pictures show transport?
- Which pictures show landmarks?
- Why did you put it there?

幼儿可能回应：

- This is the USA.
- It is a city.
- It is a landmark.
- I see a bridge.
- I put it here because it is transport.
- The taxi goes in the city group.

## 5. 建议游戏与活动

### 活动 1：地图到符号

**目的：**
用简单的地理背景引入美国，但不把课变成记忆课。

**材料：**
世界地图或地球仪、简单的美国轮廓地图、中国标记、美国标记、美国符号图片卡。

**准备：**
准备一张大的、简单的地图。在地图上清楚地标出中国和美国。

**玩法 / 做法：**
在地图上指出中国和美国。简短说明：这一阵子班级要一起探索美国。把美国符号卡摆在地图周围。幼儿选一张符号卡，贴到美国地图附近，并说一说或听一听这是什么。

**教师提示：**
不要求幼儿记住州名、首都或具体位置。地图部分只用来支持"方位感"。

### 活动 2：美国分类整理

**目的：**
建立 K3 的信息组织能力。

**材料：**
图片卡：美国地图、自由女神像、金门大桥、城市天际线、黄色出租车、汉堡、篮球、波普艺术图、好莱坞标志；分类标题：地图、城市、地标、食物、运动、艺术 / 媒体。

**准备：**
准备一块分类板或地面分类垫。

**玩法 / 做法：**
幼儿分小组给图片分类。讨论每张卡应该放在哪里。教师追问："Why is this a landmark?""Could this go in another group?"。幼儿把卡放好，并在支持下解释选择。

**教师提示：**
允许灵活的思考。有些图，比如金门大桥，可以既是地标，也和城市 / 交通相关。

### 活动 3：开始建美国信息墙

**目的：**
启动一个跨 4 节课的延续性项目输出。

**材料：**
大展示纸、分类标签、便利贴、马克笔、图片卡、胶带。

**准备：**
搭好一面空白的美国信息墙，标好分类空间。

**玩法 / 做法：**
幼儿把刚才分好类的图片挑一部分移到信息墙上。每组加一条短标签、一幅小画、或一句教师代写的句子。例："This is a landmark""A taxi is transport""This city has tall buildings"。

**教师提示：**
K3 幼儿可以贡献简短的口头或书面解释，需要时由教师代写。
