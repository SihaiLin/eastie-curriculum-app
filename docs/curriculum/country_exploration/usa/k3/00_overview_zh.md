# 美国 · K3 概览

## 1. 国家特点

美国是一个具有强烈视觉感、文化感和城市感的现代国家主题。可以从著名地标、大城市、流行食物、运动、视觉文化和与发明、媒体相关的图像来探索。孩子们可能已经在生活中接触过一些和美国有关的元素：汉堡、篮球、卡通、超级英雄、好莱坞式电影文化、黄色出租车、桥梁和自由女神像。

对 K3 幼儿来说，美国可以不止是"一组熟悉的符号"。它可以用来做信息组织、类别比较、简单解释，以及做一份小指南或一个小博物馆。整体仍然保持具体，但 K3 幼儿可以开始问：这是怎样的一个地方？哪些符号能让人认出它？我们怎么向别人介绍它？

## 2. 年级视角

K3 幼儿通过项目式探究、信息组织、简单解释和展示来认识美国。核心视角是：**"我们怎么整理和展示我们对这个国家的了解？"**

K3 可以使用城市、地标、食物、运动、艺术、媒体、轻历史符号等类别。他们可以制作一份小指南、一块发现板，或一个班级小博物馆。目标不是正式的地理或政治知识，而是"选信息—有意义地分组—做出一个作品—向同伴解释"的能力。

## 3. 教室布置与关键元素

教室可以布置成一个"美国研究与设计工作室"。建议包括：城市与地标墙、流行文化和食物桌、运动与动作角、Pop Art 波普艺术设计区，以及一个小指南或小博物馆制作站。

对 K3 来说，教室应当支持幼儿"整理信息"。标签、类别卡、地图、简单时间线、图片组、空白指南页、海报模板和搭建材料都很有用。好莱坞、五月花号、NASA、国家公园等更高阶的元素可以选择性引入，但不要让单元过载。

关键元素：美国地图 / 纽约天际线 / 自由女神像 / 金门大桥 / 黄色出租车 / 汉堡 / 篮球 / 好莱坞 / Pop Art 波普艺术 / 国家公园或 NASA 作为可选拓展

## 4. 四课地图

### 第 1 课：美国在哪里？城市、地图与地标

幼儿在世界地图的简单背景下定位美国，把主要视觉符号按"地图、城市、地标、交通"等类别组织起来。他们开始搭建一面共同使用的信息墙。

### 第 2 课：美国标志——食物、运动和流行文化

幼儿调查熟悉的美国标志：汉堡、爆米花、篮球、棒球、好莱坞式媒体、卡通、超级英雄形象。他们讨论为什么有些图像会被广泛认出。

### 第 3 课：波普艺术和视觉传达

幼儿把波普艺术看作"图像可以被重复、放大、重新着色、变成强视觉信号"的方式。他们为美国小指南做一张设计页或海报。

### 第 4 课：创建并展示一个美国小博物馆

幼儿把作品整理成美国小博物馆或小指南，挑一个部分做展示，解释"它展示的是什么、为什么选它"。
