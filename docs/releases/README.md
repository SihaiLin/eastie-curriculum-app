# EASTIE Release Notes

This folder records production releases for the EASTIE curriculum app.

## Version Format

Use this format for production releases:

```text
vYYYY.MM.DD-rN
```

Example:

```text
v2026.08.27-r1
```

`rN` means the nth production release on that date.

## Release Requirements

Every production deployment should have:

- a Git commit;
- a Git tag;
- a release note in this folder;
- a deployment verification record.

Feedback-based fixes should become a new `vYYYY.MM.DD-rN` release after deployment and verification.
